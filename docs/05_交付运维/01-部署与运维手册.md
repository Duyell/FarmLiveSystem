## 1. 部署拓扑

```text
Internet
   │ 443/80
┌──▼──────────────────────────────────────────────┐
│ Nginx（TLS、静态、反代、限流）                    │
│  ├─ /        → admin 静态                         │
│  ├─ /h5      → h5 静态                            │
│  ├─ /api     → app:8080                           │
│  └─ /ai      → ai:8000                            │
├──────────────────────────────────────────────────┤
│ app（Spring Boot）── mysql / redis / minio         │
│ ai（FastAPI）────── qdrant / mysql                 │
└──────────────────────────────────────────────────┘
```

| ai | `farm/ai:v1.0.0` | 1.5G | 否 |

## 2. 服务器初始化（Ubuntu 22.04）

```bash
# 1. 用户与 SSH
adduser deploy && usermod -aG sudo deploy
# 本地：ssh-copy-id deploy@<ip>；禁用 root 登录与密码登录

# 2. 基础
apt update && apt upgrade -y
timedatectl set-timezone Asia/Shanghai
apt install -y curl git ufw fail2ban unzip htop

# 3. 防火墙（仅 22/80/443）
ufw default deny incoming
ufw allow 22/tcp && ufw allow 80/tcp && ufw allow 443/tcp
ufw enable

# 4. Swap（4G 机器建议 2G）
fallocate -l 2G /swapfile && chmod 600 /swapfile
mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab

# 5. Docker
curl -fsSL https://get.docker.com | sh
usermod -aG docker deploy
```

```bash
TZ=Asia/Shanghai

DB_NAME=farm_live

REDIS_PASSWORD=__CHANGE__

MINIO_ROOT_USER=farmadmin
MINIO_ROOT_PASSWORD=__CHANGE__
MINIO_BUCKET=farm-qualification

JWT_SECRET=__64_CHARS__
DATA_KEY=__BASE64_32_BYTES__

```

> `.env` 权限 600，属主 deploy；禁止提交 Git；备份时单独加密。

### 3.2 Compose 关键片段

```yaml
services:
  mysql:
    image: mysql:8.0
    restart: always
    environment:
      MYSQL_DATABASE: ${DB_NAME}
      MYSQL_USER: ${DB_USER}
      MYSQL_PASSWORD: ${DB_PASSWORD}
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      TZ: Asia/Shanghai
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_0900_ai_ci
             --innodb-buffer-pool-size=2G --slow-query-log=1 --long-query-time=0.5
    volumes:
      - ./data/mysql:/var/lib/mysql
      - ./deploy/sql:/docker-entrypoint-initdb.d:ro
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      interval: 10s

  redis:
    image: redis:7.2-alpine
    restart: always
    command: redis-server --appendonly yes --requirepass ${REDIS_PASSWORD}
    volumes: ["./data/redis:/data"]

  minio:
    image: minio/minio:RELEASE.2024-10-13T13-34-11Z
    restart: always
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: ${MINIO_ROOT_USER}
      MINIO_ROOT_PASSWORD: ${MINIO_ROOT_PASSWORD}
    volumes: ["./data/minio:/data"]

  qdrant:
    image: qdrant/qdrant:v1.9.0
    restart: always
    volumes: ["./data/qdrant:/qdrant/storage"]

  app:
    image: farm/app:${APP_VERSION}
    restart: always
    env_file: .env
    depends_on:
      mysql: {condition: service_healthy}
      redis: {condition: service_started}
    expose: ["8080"]

  ai:
    image: farm/ai:${AI_VERSION}
    restart: always
    env_file: .env
    expose: ["8000"]

  nginx:
    image: nginx:1.24-alpine
    restart: always
    ports: ["80:80", "443:443"]
    volumes:
      - ./nginx/conf.d:/etc/nginx/conf.d:ro
      - ./nginx/certs:/etc/nginx/certs:ro
      - ./data/static:/usr/share/nginx/html:ro
```

### 3.3 启动

```bash
cd /opt/farm
docker compose pull
docker compose up -d
docker compose ps
curl -fsS https://farm.example/actuator/health   # 经 Nginx 内网限制
```

### 3.4 初始化

```bash
# 迁移（Flyway 随 app 启动执行；也可手动）
docker compose exec app java -jar app.jar --flyway-migrate-only

# 种子（仅首次）
docker compose exec -T mysql mysql -u$DB_USER -p$DB_PASSWORD $DB_NAME < deploy/sql/seed.sql

# MinIO 桶
docker compose exec minio mc alias set local http://localhost:9000 $MINIO_ROOT_USER $MINIO_ROOT_PASSWORD
docker compose exec minio mc mb -p local/$MINIO_BUCKET
```

## 4. 发布流程

```text
1. 代码冻结 → CI 构建镜像 farm/app:vX.Y.Z、farm/ai:vX.Y.Z
2. 镜像扫描（Trivy）→ 推送镜像仓库
3. 发布前备份（DB + MinIO + .env）
4. 拉取新镜像 → 执行迁移（向前兼容）
5. 启动新版本 → 冒烟测试
6. 观察 30 分钟（错误率/延迟/日志）
7. 记录发布台账；失败则回滚
```

### 4.1 冒烟测试（每次发布）

- [ ] 登录 4 角色
- [ ] 农户提交 1 条预约
- [ ] 管理员审核通过
- [ ] 取消并验证候补
- [ ] 统计页打开
- [ ] 问答返回 1 条带引用答案
- [ ] 通知发送 1 条
- [ ] 健康检查 UP

### 4.2 回滚

```bash
# 应用回滚（镜像）
sed -i 's/^APP_VERSION=.*/APP_VERSION=previous/' .env
docker compose up -d app
# 数据库：优先"向前兼容"，不自动回滚；若必须回滚，用发布前备份恢复
```

**原则**：迁移脚本必须向前兼容（先加列/双写，后删旧列）；禁止在发布窗口删除列。

## 5. Nginx 与 TLS

```nginx
server {
    listen 443 ssl http2;
    server_name farm.example;

    ssl_certificate     /etc/nginx/certs/fullchain.pem;
    ssl_certificate_key /etc/nginx/certs/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    add_header Strict-Transport-Security "max-age=31536000" always;
    add_header X-Content-Type-Options nosniff always;
    add_header X-Frame-Options DENY always;

    client_max_body_size 21m;

    location / { root /usr/share/nginx/html/admin; try_files $uri $uri/ /index.html; }
    location /h5 { alias /usr/share/nginx/html/h5; try_files $uri $uri/ /h5/index.html; }

    location /api/ {
        proxy_pass http://app:8080;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }

    location /api/v1/ai/ {
        proxy_pass http://app:8080;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
        proxy_buffering off;
        proxy_read_timeout 120s;
    }
}
```

TLS：Certbot 自动续期（`certbot renew --deploy-hook "docker compose exec nginx nginx -s reload"`）；每月检查到期日。

## 6. 监控与告警

| 监控项 | 阈值 | 动作 |
|---|---|---|
| 站点可用性 | 连续 2 次失败 | 短信/电话告警 P5 |
| 5xx 比例 | >1%（5min） | 告警 + 查日志 |
| 接口 P95 | 超目标 2 倍 | 查慢 SQL/GC |
| JVM Heap | >85% | 查泄漏/扩容 |
| DB 连接 | >80% | 查长事务 |
| 磁盘 | >80% | 清理日志/备份 |
| Outbox 积压 | >1000 | 查消费/DB |
| 通知 DEAD | >10/小时 | 查供应商 |
| LLM 成功率 | <95% | 切备/降级 |
| 备份 | 失败 | 立即重跑 + 告警 |

工具：Uptime Kuma（探测）、Actuator + Prometheus/Grafana（可选）、日志关键字告警（ERROR/Exception）。

## 7. 备份与恢复

### 7.1 策略

| 对象 | 方式 | 频率 | 保留 |
|---|---|---|---|
| MySQL 全量 | `mysqldump --single-transaction` + gzip + gpg | 每日 01:00 | 7 日 + 4 周 + 6 月 |
| MySQL 增量 | binlog 归档 | 每小时 | 7 天 |
| MinIO | `mc mirror` 到备份桶/异地 | 每日 02:00 | 30 天 |
| 配置 | `.env`、nginx、compose 加密打包 | 每次变更 | 10 版 |
| 代码 | Git tag | 每次发布 | 永久 |

### 7.2 备份脚本（cron）

```bash
#!/usr/bin/env bash
set -euo pipefail
DATE=$(date +%F)
BACKUP=/opt/farm/backup/db
mkdir -p "$BACKUP"
docker compose exec -T mysql mysqldump -u"$DB_USER" -p"$DB_PASSWORD" \
  --single-transaction --routines --triggers "$DB_NAME" \
  | gzip | gpg --encrypt --recipient farm-backup > "$BACKUP/farm-$DATE.sql.gz.gpg"
find "$BACKUP" -name 'farm-*.sql.gz.gpg' -mtime +30 -delete
```

```cron
0 1 * * * /opt/farm/deploy/scripts/backup-db.sh >> /opt/farm/logs/backup.log 2>&1
0 2 * * * /opt/farm/deploy/scripts/backup-minio.sh >> /opt/farm/logs/backup.log 2>&1
```

### 7.3 恢复步骤（每月演练）

```bash
# 1. 停应用（避免写入）
docker compose stop app ai

# 2. 恢复全量
gunzip -c farm-2026-10-18.sql.gz.gpg | gpg --decrypt \
  | docker compose exec -T mysql mysql -u"$DB_USER" -p"$DB_PASSWORD" "$DB_NAME"

# 3. 应用 binlog 到故障点（可选）
# mysqlbinlog --stop-datetime="..." binlog.0000xx | mysql ...

# 4. 校验
# - 行数对比、最近 10 条预约、资源占用无重复、日志链校验
# 5. 启动并冒烟
docker compose start app ai
```

**RPO ≤15min、RTO ≤2h**；演练记录写入运维台账。

## 8. 故障处置 Runbook

| 现象 | 排查 | 处置 | 升级 |
|---|---|---|---|
| 站点 502 | `docker compose ps`；app 日志 | 重启 app；看 OOM/端口 | 15min 未恢复 → P2 |
| DB 连接满 | `show processlist`；长事务 | kill 长事务；重启连接池 | 30min → P2 |
| Redis 不可用 | `redis-cli ping`；内存 | 重启；必要时禁用缓存降级 | 15min → P2 |
| 磁盘满 | `df -h`；日志/备份 | 清日志/旧备份；扩容 | 立即 |
| 内存 OOM | `dmesg`；docker stats | 重启；限流；升配 | 30min → P2 |
| 短信失败 | 供应商状态；余额 | 切备；站内兜底 | 30min → P5 |
| LLM 失败 | API 状态/额度 | 切备；关闭 AI 入口 | 30min → P2 |
| Outbox 积压 | 消费日志；DB 锁 | 重启消费者；扩容 | 1h → P2 |
| 队列错乱 | 对账 SQL；Redis ZSET | 以 DB 重建 ZSET | 立即 → P2 |
| 证书过期 | `openssl s_client` | certbot renew；reload | 立即 |
| 数据误删 | 确认范围 | 停写 → 恢复备份 → 补 binlog | 立即 → P1 |

## 9. 安全加固

- 仅 22/80/443 开放；SSH 密钥 + fail2ban；禁 root。
- 数据库/Redis/MinIO/Qdrant 仅 Docker 内网，不映射公网。
- 容器非 root 运行；只读文件系统（除数据卷）。
- 镜像扫描无 Critical；每月重建基础镜像。
- 生产关闭 Swagger/Actuator env；健康检查限内网。
- 日志不落敏感信息；日志权限 640。
- 自动安全更新（unattended-upgrades）；每月补丁窗口。
- 密钥 12 个月轮换；人员变动立即轮换。
