## 8. 当前进度

- 登录验证码、连续失败锁定、改密、角色跳转、基础数据 CRUD 已完成；
- 区域字典、区域接口、农户/场地三级选择已完成；
- 农户资质材料上传、审核、下载已完成；
- 农户/设备修改记录原因和前后值；
- 预约提交、审核、取消、场次完成、预约调整已完成；
- 排队、候补、24 小时关闭已完成；
- 五类通知、通知模板、未读数已完成；
- 销售录入、四项统计指标、完成场次明细、CSV 导出已完成；
- 数据统计员只能看聚合指标和趋势，明细/导出只给直播管理员和系统管理员；
- 工作台待审核、今日直播、可用资源已完成；
- 操作日志已覆盖账号、农户、场地、设备、预约、调整、完成、销售和资质审核；
- 手机网页基础响应式已完成，375–428 像素真机回归待做；
- 二次验证、AI 助手、农户个人统计还没做。
