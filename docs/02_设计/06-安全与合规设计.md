## 1. 安全目标

| 目标 | 可验证标准 |
|---|---|
| 数据机密性 | 手机号/资质文件加密存储；全站 TLS；密钥不入库不入仓 |
| 最小必要 | 只收集预约所需字段；无身份证/住址/银行卡 |
| 访问可控 | 4 角色权限矩阵 100% 生效；越权用例 100% 拦截 |
| 操作可追溯 | 敏感操作 100% 审计；日志 ≥6 个月；可校验未被篡改 |
| 可恢复 | 每日备份；RPO ≤15min、RTO ≤2h；每月恢复演练 |
| 合规可证 | 隐私政策、授权记录、删除/导出通道、处理记录齐全 |

## 2. 数据分类分级

| 级别 | 定义 | 数据 | 保护措施 |
|---|---|---|---|
| L4 极敏感 | 泄露造成重大伤害 | 密码哈希、加密密钥 | 不可逆/密钥隔离、最小权限、审计 |
| L3 敏感个人信息 | 可识别自然人 | 手机号、资质材料、直播地址 | 加密、脱敏、二次验证、审计 |
| L2 内部数据 | 业务运营数据 | 预约、排队、设备、统计 | 登录 + 角色 + 数据范围 |
| L1 公开数据 | 可公开 | 场地名称、开放时段、知识库 | 常规防护 |

> **禁止收集**：身份证号、家庭住址、银行卡号、人脸、生物特征、精确位置轨迹。需求评审与 CI 双重拦截。

## 3. 《个人信息保护法》合规映射

| PIPL 原则 | 本项目落地 | 证据 |
|---|---|---|
| 合法、正当、必要、诚信 | 仅收集预约必需字段；字段清单评审 | SRS §7、字段清单 |
| 告知同意 | 首次登录/预约前展示隐私政策与授权勾选；记录版本与时间 | `consent_record`（可并入审计） |
| 目的限制 | 手机号仅用于通知与身份核验；不用于营销 | 数据流图、代码评审 |
| 最小必要 | 列表脱敏；导出默认脱敏；无批量全号接口 | 接口清单、测试报告 |
| 存储期限最短 | 日志 6 个月、通知 180 天、导出文件 24h、注销后 6 个月删除 | 留存策略表 |
| 个人权利 | 本人可查/更正/导出/删除（注销） | 个人中心、工单 |
| 委托处理 | 短信/LLM 供应商签数据处理协议；不传全量个人信息 | 合同、脱敏证据 |
| 跨境 | 全部境内服务；LLM 选境内供应商 | 选型记录 |
| 安全措施 | 加密、RBAC、审计、备份、应急预案 | 本文 + 测试报告 |
| 泄露通知 | 30 分钟止血、评估、按法规告知 | 应急流程 |

### 3.1 同意的粒度

- 必需：隐私政策 + 个人信息处理规则（不勾选不可预约）。
- 可选：短信通知（可关闭非关键短信）、第三方平台同步（默认关闭）。
- 撤回：个人中心可关闭可选授权；撤回不影响已完成的合法处理。

### 3.2 个人权利实现

| 权利 | 实现 | 时限 |
|---|---|---|
| 查阅 | 个人中心查看档案、预约、排队、通知 | 实时 |
| 更正 | 手机号变更需二次验证；姓名/县域由管理员审核 | 3 个工作日 |
| 导出 | 本人数据导出（脱敏 PDF/Excel） | 3 个工作日 |
| 删除/注销 | 提交申请 → 管理员审核 → 逻辑删除 + 30 天后匿名化 | 15 个工作日 |
| 解释 | 隐私政策 + 人工客服 | — |

### 4.2 数据范围

| 角色 | 范围 | 实现 |
|---|---|---|
| SYS_ADMIN | 全部 | 不加条件 |
| LIVE_ADMIN | 所辖县域（可配置多县） | SQL 追加 `county_code IN (...)` |
| FARMER | 仅本人 | 追加 `farmer_id = 当前用户` |
| STAT_VIEWER | 授权县域/全部（只读） | 追加范围 + 拒绝写方法 |

### 4.3 越权防护

- **纵向**：接口注解 + 权限码校验；管理端接口不得被 H5 token 调用。
- **横向**：资源归属校验（IDOR）；禁止仅靠前端隐藏；403 不泄露资源存在性。
- **参数**：服务端忽略客户端传入的 `userId/farmerId/role`，以会话为准。
- **测试**：横向 20 条 + 纵向 15 条，100% 拦截（T4-03）。

## 5. 加密与脱敏

### 5.1 传输

- TLS 1.2+（优先 1.3）；HSTS `max-age=31536000`；禁用弱套件。
- 内部服务也走 TLS 或 Docker 内网隔离；数据库不暴露公网。

### 5.2 存储

| 数据 | 算法 | 说明 |
|---|---|---|
| 手机号 | AES-256-GCM | 每条随机 nonce；密文 `base64(nonce‖ct‖tag)` |
| 手机号检索 | HMAC-SHA256(规范化号码) | 仅用于精确匹配，不可逆 |
| 资质文件 | AES-256-GCM（信封加密） | 文件密钥由主密钥包裹；MinIO 私有桶 |
| 密码 | Argon2id（m=64MB, t=3, p=1）或 bcrypt cost≥12 | 加盐；不可逆 |
| JWT | HS256（≥256bit 密钥）或 RS256 | 短期 + 黑名单 |
| 备份 | AES-256 + 独立密钥 | 与生产密钥分离 |

### 5.3 密钥管理

- 密钥放环境变量/密钥管理服务；**禁止**入库、入 Git、入日志、入镜像。
- 启动时校验密钥存在且长度合规；缺失则拒绝启动（生产）。
- 轮换：12 个月或泄露时立即；轮换需重加密脚本 + 双密钥过渡 + 回滚预案。
- 权限：仅 P2/P5 可读取生产密钥；操作留痕。

### 5.4 脱敏规则

| 字段 | 规则 | 示例 |
|---|---|---|
| 手机号 | 前 3 + `****` + 后 4 | `138****5678` |
| 姓名 | 保留姓，名 `*`（导出时可选） | `王**` |
| 设备编号 | 完整展示（非个人信息） | `ZB-C001-01` |
| 地址 | 仅到县域/场地 | `安徽省淮南市寿县` |
| 日志 | 正则替换手机号/身份证 | — |
| AI 问题 | 发送前脱敏 | — |

**明文查看**：仅本人或系统管理员；系统管理员需二次验证 + 填写原因；每次查看写审计（谁、何时、哪条、原因）。直播管理员仅见掩码。

## 6. 认证与二次验证

### 6.1 登录

- 账号 + 密码 + 图形验证码；连续 5 次失败锁定 15 分钟。
- 密码策略：≥8 位，含字母 + 数字；禁止弱口令表；90 天提示更换（不强制）。
- 会话：access 2h、refresh 7d；登出/改密/停用立即失效。
- 单点：同一账号最多 3 个活跃会话，超出踢最早。

### 6.2 二次验证（Step-up）

| 场景 | 触发 | 验证方式 | 有效期 |
|---|---|---|---|
| 查看完整手机号（仅 SYS_ADMIN） | 点击"查看" | 密码 + 动态码 + 填写原因 | 5 分钟 |
| 删除农户 | 提交删除 | 密码 + 动态码 + 输入"删除" | 单次 |
| 强制取消预约 | 提交 | 密码 + 动态码 + 原因 | 单次 |
| 导出含完整手机号报表（仅 SYS_ADMIN） | 创建任务 | 密码 + 动态码 + 填写原因 | 单次 |
| 修改角色权限 | 保存 | 密码 + 动态码 | 单次 |
| 修改系统配置 | 保存 | 密码 + 动态码 | 单次 |
| 删除知识库文档 | 确认 | 密码 + 动态码 | 单次 |
| 日志导出 | 创建 | 密码 + 动态码 | 单次 |

- 失败 3 次锁定 10 分钟并告警。
- 动态码：短信/TOTP；开发环境用固定测试码（仅 dev profile，生产禁用）。

## 7. 应用安全（OWASP Top 10 对照）

| 风险 | 本项目措施 | 验证 |
|---|---|---|
| A01 访问控制失效 | RBAC + 数据范围 + IDOR 校验 + 403 统一 | 越权用例 35 条 |
| A02 加密失效 | TLS + AES-GCM + Argon2id + 密钥管理 | 配置核查/抓包 |
| A03 注入 | 参数绑定、白名单排序、输入校验 | SQLMap/ZAP |
| A04 不安全设计 | 威胁建模、状态机、限流、二次验证 | 设计评审 |
| A05 配置错误 | 最小镜像、关闭调试、默认拒绝、CSP | 基线扫描 |
| A06 组件漏洞 | 依赖锁定、Dependency-Check、Trivy | 无 Critical/High |
| A07 认证失效 | 锁定、会话失效、JWT 校验、防重放 | 认证用例 |
| A08 数据完整性 | 哈希链、签名 URL、幂等 | 日志校验 |
| A09 日志监控不足 | 结构化日志、告警、traceId | 告警演练 |
| A10 SSRF | 禁用户可控 URL 请求；LLM 仅固定域名 | 代码评审 |

### 7.1 输入校验

- 长度/类型/枚举/范围白名单；拒绝未知字段（`FAIL_ON_UNKNOWN_PROPERTIES`）。
- 排序字段白名单，禁止 `order by ${}`。
- 富文本仅知识库标题/描述，白名单标签；其余纯文本转义。
- 文件：扩展名 + MIME 魔数 + 大小 + 图片重编码（去 EXIF）。

### 7.2 安全响应头

```text
Strict-Transport-Security: max-age=31536000; includeSubDomains
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
Referrer-Policy: strict-origin-when-cross-origin
Permissions-Policy: geolocation=(), microphone=(), camera=()
Content-Security-Policy: default-src 'self'; img-src 'self' data: https:; style-src 'self' 'unsafe-inline'; script-src 'self'
```

### 7.3 限流与防刷

- 登录、短信、预约、问答、导出分别限流（见 D2-04 §1.5）。
- 短信同用户 1 条/分钟、5 条/天；异常触发图形验证。
- 防撞库：失败计数 + 锁定 + IP 维度限流。

### 7.4 AI 特有安全

- **提示词注入**：用户输入视为数据；系统提示与用户输入分隔；不暴露系统提示；输出过滤敏感模式。
- **只读边界**：AI 服务无业务写权限；不注册任何写工具；Java 侧不暴露写接口给 AI。
- **数据最小化**：发送 LLM 前脱敏手机号/姓名；不发送资质文件。
- **内容安全**：拒绝违法/有害请求；敏感词过滤；回答附来源。
- **越权**：AI 检索仅返回当前用户有权访问的知识库范围（V1 全公开规则文档）。

## 8. 审计日志

### 8.1 必记字段

操作人、角色、时间、操作类型、对象类型/ID、操作内容、before/after（敏感操作）、IP、UA、traceId、结果、失败原因。

### 8.2 必记事件

登录/登出/失败、农户增删改、资质审核、手机号查看、设备/场地变更、预约提交/审核/调整/取消、排队/候补操作、通知模板变更、权限变更、配置变更、导出、日志查询/导出、知识库变更、AI 转人工。

### 8.3 不可篡改

- 应用账号仅 `INSERT/SELECT`，无 `UPDATE/DELETE` 权限。
- 每条记录 `chain_hash = SHA256(prev_hash ‖ 规范化字段)`；每日生成 `audit_chain.root_hash`。
- 每日校验任务比对；异常告警并锁定可疑时间段。
- 日志归档加密；留存 ≥6 个月（等保参考），归档 5 年。

### 8.4 日志本身的安全

- 不记录密码、token、完整手机号、资质内容。
- 日志文件权限 640；仅运维可读；访问留痕。
- 导出需二次验证 + 审计。

## 11. 安全测试与漏洞管理

| 阶段 | 活动 | 工具 |
|---|---|---|
| 开发 | 代码评审、依赖扫描、密钥扫描 | Sonar、Dependency-Check、Gitleaks |

**漏洞修复 SLA**：Critical 24h、High 3 天、Medium 本迭代、Low 下迭代。修复后必须回归并更新用例。

### 11.1 安全事件响应

```text
发现 → 30 分钟内止血（下线/限流/改密） → 评估影响（哪些数据/多少人）
 → 按法规与客户要求告知 → 修复与验证 → 复盘（5 Why） → 更新预案
```

**联系人**：P2 安全负责人、P5 运维、P1 对外沟通。

## 12. 明确禁止

1. 存储身份证号、家庭住址、银行卡号、人脸/指纹。
2. 提供任何"输入掩码反查完整信息"的功能。
3. 批量导出完整手机号（无二次验证/无审计）。
4. 在日志、异常、前端 console 打印敏感信息。
5. 将生产数据复制到开发/测试环境（必须脱敏）。
6. 使用境外 LLM/云服务处理个人信息。
7. 关闭鉴权"临时联调"后忘记恢复。
8. 共享账号、明文密码、把密钥提交到 Git。
