## 1. 通用约定

### 1.1 请求

| 项 | 约定 |
|---|---|
| 方法 | GET 查询、POST 创建/动作、PUT 全量更新、PATCH 局部更新、DELETE 删除 |
| 编码 | `Content-Type: application/json; charset=utf-8`；上传 `multipart/form-data` |
| 认证 | `Authorization: Bearer <accessToken>` |
| 幂等 | `Idempotency-Key: <uuid>`（创建类接口必传，24h 有效） |
| 二次验证 | `X-Step-Up-Token: <token>`（敏感接口必传） |
| 追踪 | 服务端生成 `traceId`，响应头 `X-Trace-Id` 返回 |
| 时间 | ISO-8601 带时区：`2026-10-20T10:00:00+08:00` |
| ID | JSON 中 BIGINT 一律**字符串**，避免 JS 精度丢失 |
| 枚举 | 大写下划线：`PENDING_REVIEW` |
| 空值 | 不适用字段可省略；显式空用 `null`；列表用 `[]` |

### 1.2 统一响应

```json
{
  "code": "OK",
  "message": "成功",
  "data": {},
  "traceId": "01JABCDEFGHJKLMNPQRSTUVWXY",
  "timestamp": "2026-10-19T13:36:04+08:00"
}
```

- `code`：字符串错误码，成功恒为 `OK`。
- HTTP 状态码与 `code` 同时表达语义（4xx/5xx + 具体码）。
- 校验失败时 `data.errors` 为字段级数组：

```json
{
  "code": "PARAM_INVALID",
  "message": "参数校验失败",
  "data": {
    "errors": [
      {"field": "startTime", "reason": "必须为整点"},
      {"field": "products[0].name", "reason": "长度需在 2-30 字"}
    ]
  }
}
```

### 1.3 分页

请求：`page`（从 1 开始，默认 1）、`size`（20/50/100，默认 20）、`sort`（如 `createdAt,desc`）。

```json
{
  "code": "OK",
  "data": {
    "items": [],
    "page": 1,
    "size": 20,
    "total": 128,
    "hasNext": true
  }
}
```

> 深翻页（>1 万）改用游标：`lastId`；导出走异步任务，不受分页限制。

### 1.4 鉴权与权限

- JWT access 2h、refresh 7d；登出/改密后 access 立即失效（Redis 黑名单）。
- 角色：`SYS_ADMIN` / `LIVE_ADMIN` / `FARMER` / `STAT_VIEWER`。
- 接口权限码：`<模块>:<动作>`，如 `booking:review`；无权限返回 403。
- 数据权限：农户仅本人；直播管理员按 `county_code`；统计员只读。
- 敏感接口（删除农户、查看全号、强制取消、导出含个人信息、改角色、改配置）需 `X-Step-Up-Token`。

### 1.5 限流

| 场景 | 限制 | 返回 |
|---|---|---|
| 登录 | 5 次/分钟/账号 + 20 次/分钟/IP | 429 `RATE_LIMITED` |
| 短信发送 | 1 条/分钟/用户 | 429 |
| 预约提交 | 10 次/分钟/用户 | 429 |
| 问答 | 10 次/分钟/用户 | 429 |
| 导出 | 3 次/小时/用户 | 429 |
| 通用读 | 100 次/分钟/用户 | 429 |

响应头：`X-RateLimit-Limit`、`X-RateLimit-Remaining`、`Retry-After`。

### 1.6 幂等与并发

| 接口 | 幂等键 | 冲突返回 |
|---|---|---|
| 创建预约 | `Idempotency-Key` | 200 首次结果 / 409 |
| 审核 | `version` 字段 | 409 `INVALID_STATE` |
| 加入排队 | 业务唯一索引 | 409 `ALREADY_QUEUED` |
| 候补确认 | `offerId + status` | 409 `OFFER_HANDLED` |
| 导出 | `Idempotency-Key` | 返回已有任务 |

## 2. 错误码目录

| HTTP | code | 含义 | 前端处理 |
|---|---|---|---|
| 400 | `PARAM_INVALID` | 参数校验失败 | 字段级提示 |
| 400 | `PARAM_FORBIDDEN` | 含禁存字段/非法参数 | 提示不可提交 |
| 400 | `SLOT_NOT_ALIGNED` | 时段非整点 | 引导重选 |
| 400 | `SLOT_CROSS_DAY` | 跨天 | 引导重选 |
| 400 | `SLOT_DURATION_INVALID` | 时长非法 | 提示 1–4 小时 |
| 400 | `SLOT_TOO_SOON` | 提前量不足 | 提示最近可约时间 |
| 400 | `SLOT_TOO_FAR` | 超出 30 天 | 提示窗口 |
| 400 | `OUT_OF_OPEN_HOURS` | 超出场地开放时段 | 展示开放时段 |
| 400 | `RESOURCE_MISMATCH` | 设备与场地不匹配 | 刷新资源 |
| 400 | `DUPLICATE_PRODUCT` | 农产品重复 | 高亮重复项 |
| 400 | `EXPORT_TOO_LARGE` | 导出超上限 | 提示缩小范围 |
| 401 | `UNAUTHORIZED` | 未登录/令牌无效 | 跳登录 |
| 401 | `TOKEN_EXPIRED` | 令牌过期 | 静默刷新，失败跳登录 |
| 403 | `FORBIDDEN` | 无权限 | 403 页 |
| 403 | `FARMER_NOT_CERTIFIED` | 未认证 | 引导认证 |
| 403 | `ACCOUNT_DISABLED` | 账号停用 | 提示联系管理员 |
| 403 | `ADJUST_WINDOW_CLOSED` | 超 12h 调整窗口 | 仅展示取消 |
| 403 | `COOLING_DOWN` | 冷却期 | 展示解禁时间 |
| 403 | `STEP_UP_REQUIRED` | 需二次验证 | 弹验证框 |
| 404 | `NOT_FOUND` | 资源不存在 | 空态 |
| 409 | `RESOURCE_CONFLICT` | 资源冲突 | 展示冲突 + 排队入口 |
| 409 | `DEVICE_UNAVAILABLE` | 设备不可用 | 重新选资源 |
| 409 | `INVALID_STATE` | 状态非法流转 | 刷新详情 |
| 409 | `DUPLICATE_BOOKING` | 重复预约 | 展示已有单号 |
| 409 | `FARMER_TIME_CONFLICT` | 同农户同时段冲突 | 提示已有预约 |
| 409 | `ALREADY_QUEUED` | 已在队列 | 展示排队号/顺位 |
| 409 | `OFFER_HANDLED` | 候补已处理 | 刷新状态 |
| 429 | `RATE_LIMITED` | 限流 | 倒计时重试 |
| 500 | `INTERNAL_ERROR` | 系统异常 | 展示 traceId |
| 503 | `SERVICE_DEGRADED` | 依赖降级 | 提示能力受限 |
| 503 | `LLM_UNAVAILABLE` | AI 不可用 | 切 FAQ/人工 |

> **安全要求**：403 与 404 文案不得泄露资源是否存在；生产环境不返回堆栈。

## 4. 核心接口契约

### 4.1 登录

`POST /api/v1/auth/login`

```json
{
  "username": "admin",
  "password": "********",
  "captchaId": "c-123",
  "captchaCode": "8K2M"
}
```

```json
{
  "code": "OK",
  "data": {
    "accessToken": "eyJ...",
    "refreshToken": "eyJ...",
    "expiresIn": 7200,
    "user": {
      "id": "10001",
      "username": "admin",
      "realName": "张三",
      "roleCode": "SYS_ADMIN",
      "countyCode": null,
      "permissions": ["farmer:read", "booking:review"]
    }
  }
}
```

失败：401 `UNAUTHORIZED`；锁定：403 `ACCOUNT_LOCKED`（含 `lockedUntil`）。

### 4.2 提交预约

`POST /api/v1/bookings`　`Authorization: Bearer ...`　`Idempotency-Key: 7f3c...`

```json
{
  "countyCode": "341521",
  "theme": "寿县草莓专场",
  "venueId": "2001",
  "deviceId": "3001",
  "startTime": "2026-10-20T10:00:00+08:00",
  "endTime": "2026-10-20T12:00:00+08:00",
  "products": [
    {"name": "红颜草莓", "spec": "5斤装"},
    {"name": "圣女果", "spec": "3斤装"}
  ]
}
```

成功 `201`：

```json
{
  "code": "OK",
  "data": {
    "bookingId": "50001",
    "bookingNo": "Y202610190001",
    "status": "PENDING_REVIEW",
    "startTime": "2026-10-20T10:00:00+08:00",
    "endTime": "2026-10-20T12:00:00+08:00",
    "venueId": "2001",
    "deviceId": "3001",
    "estimatedReviewHours": 24
  }
}
```

冲突 `409 RESOURCE_CONFLICT`：

```json
{
  "code": "RESOURCE_CONFLICT",
  "message": "目标时段资源已被占用",
  "data": {
    "conflicts": [
      {"resourceType": "DEVICE", "resourceId": "3001", "slotStart": "2026-10-20T10:00:00+08:00"},
      {"resourceType": "VENUE",  "resourceId": "2001", "slotStart": "2026-10-20T10:00:00+08:00"}
    ],
    "queueAvailable": true,
    "estimatedPosition": 3
  }
}
```

> 前端据 `queueAvailable` 展示"进入排队"，调用 `POST /queues` 并带上原请求参数与 `conflictToken`（10 分钟有效）。

### 4.3 审核预约

`POST /api/v1/bookings/{id}/review`

```json
{
  "result": "REJECTED",
  "comment": "资质照片模糊，请重新上传后预约",
  "recommendedStart": "2026-10-21T10:00:00+08:00",
  "version": 3
}
```

- `APPROVED`：`comment` 可空；`recommendedStart` 忽略。
- `REJECTED`：`comment` ≥5 字且 `recommendedStart` 必填，且不得与占用冲突。
- 成功返回最新 `status`、`reviewedAt`、`version`；并发冲突 409 `INVALID_STATE`。

### 4.4 加入排队

`POST /api/v1/queues`

```json
{
  "bookingDraft": {
    "countyCode": "341521",
    "theme": "寿县草莓专场",
    "venueId": "2001",
    "deviceId": "3001",
    "startTime": "2026-10-20T10:00:00+08:00",
    "endTime": "2026-10-20T12:00:00+08:00",
    "products": [{"name": "红颜草莓", "spec": "5斤装"}]
  },
  "conflictToken": "ct-9f2..."
}
```

## 5. 接口安全要求

| 项 | 要求 |
|---|---|
| 认证 | 除 login/refresh/captcha/health 外全部鉴权 |
| 越权 | 每次访问资源校验归属；不得仅靠前端隐藏 |
| 注入 | 参数绑定 + 白名单排序字段；禁止拼接 |
| XSS | 富文本仅知识库管理端，白名单过滤；其余纯文本 |
| 文件 | 类型魔数 + 大小 + 重命名 + 私有桶 |
| 敏感返回 | 列表永不返回明文手机号/资质原文件 |
| 错误 | 不返回堆栈/SQL/内部地址 |
| CORS | 仅允许管理端与 H5 域名 |
| 日志 | 记录 traceId/用户/耗时/状态，不记录密码/token/全号 |
| 重放 | 幂等键 + 时间戳校验（可选） |

## 6. 契约管理与联调

1. **单一来源**：代码注解 + springdoc 生成 `openapi.json`；CI 归档为构建产物。
2. **变更流程**：字段新增（兼容）→ P2 批准；字段删除/改类型/改语义（破坏）→ CCB + 版本升级。
3. **Mock**：Apifox 导入 OpenAPI，前后端按示例数据并行；Mock 必须覆盖 200/400/403/409。
4. **契约测试**：P5 用 REST Assured 校验响应 schema；CI 失败阻断合并。
5. **联调准入**：接口在测试环境可用 + Swagger 示例可跑通 + 错误码齐全。
6. **联调完成定义**：前后端双方用例通过、异常分支验证、日志有 traceId、性能达标。

---

## 7. 版本与弃用

- 路径版本 `/api/v1`；破坏性变更开 `/api/v2`，旧版至少保留 1 个迭代。
- 弃用响应头：`Deprecation: true`、`Sunset: <date>`、`Link: <new>`。
- 文档同步：OpenAPI、Apifox、RTM、前端类型定义四处必须一致。
