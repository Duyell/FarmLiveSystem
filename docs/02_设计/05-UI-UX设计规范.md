# 助农直播管理系统 · UI/UX 设计规范

| 项 | 内容 |
|---|---|
| 文档编号 | D2-05 |
| 版本 | v1.0 |
| 编制/审核 | P6 / P1 / P3 |
| 设计工具 | Figma（主）/ 即时设计（备） |
| 组件库 | Element Plus 2.7（PC）/ Vant 4.9（H5） |
| 原型参考 | `docs/assets/prototypes/` 三张图 |

> 目标：**农户 3 步约上直播，管理员一屏看懂资源**。所有页面必须回答三个问题：我现在在哪、我能做什么、做完会怎样。

---

## 1. 设计原则

| # | 原则 | 落地要求 |
|---|---|---|
| 1 | **农户优先** | H5 主流程 ≤3 步；字段少而准；错误提示说"怎么改"而不是"你错了" |
| 2 | **状态可见** | 预约/排队/候补的每个状态都有文字 + 颜色 + 下一步动作 |
| 3 | **助农气质** | 绿色主色 + 米色底，避免"科技蓝"；文案朴实，不用"赋能/闭环"等黑话 |
| 4 | **一屏决策** | 管理端列表首屏展示关键字段与操作，详情再展开 |
| 5 | **防错优于纠错** | 危险操作二次确认；不可用资源置灰并说明原因；提交前摘要确认 |
| 6 | **可访问** | 对比度 ≥4.5:1；不只靠颜色传达状态；触控 ≥44px；支持键盘 |
| 7 | **一致** | 同一状态在列表/详情/通知中颜色与文案一致 |

  --color-bg-subtle:      #F5EFE6;

  /* 语义色 */
  --color-success:        #2E7D32;
  --color-warning:        #F59E0B;
  --color-danger:         #DC2626;
  --color-info:           #2563EB;

> 与原型一致：侧边栏选中态 `#E8F5E9` + 左侧 3px 主色条；主按钮 `#2E7D32`；页面底 `#FAF7F2`；卡片白底。

### 2.2 字体与字号

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| H1 | 28/36 | 600 | 页面主标题（H5 24/32） |
| H2 | 20/28 | 600 | 区块标题 |
| H3 | 16/24 | 600 | 卡片标题 |
| Body | 14/22 | 400 | 正文、表格 |
| Caption | 12/18 | 400 | 辅助说明、时间 |
| Number | 32/40 | 700 | 指标数字（等宽数字） |

字体栈：`"PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`；数字用 `font-variant-numeric: tabular-nums`。

### 2.3 间距、圆角、阴影

| 令牌 | 值 | 用途 |
|---|---|---|
| space-1/2/3/4/6/8 | 4/8/12/16/24/32px | 统一 8 栅格 |
| radius-sm/md/lg | 6/8/12px | 按钮/卡片/弹窗 |
| shadow-card | `0 1px 3px rgba(0,0,0,.06)` | 卡片 |
| shadow-pop | `0 8px 24px rgba(0,0,0,.12)` | 弹窗/下拉 |
| border-width | 1px | 统一 |

### 2.4 图标与插图

- 图标：Element Plus Icons / Vant Icons，线性 1.5px；主色或中性色。
- 空状态：轻量插画（农田/直播/日历），配一句行动建议 + 主按钮。
- 禁止：emoji 作为功能图标；多套图标混用。

## 3. 布局规范

### 3.1 管理端（PC）

```text
┌────────────────────────────────────────────────────┐
│ 顶栏 64px：Logo | 面包屑 | 通知 | 用户                 │
├──────────┬─────────────────────────────────────────┤
│ 侧边栏    │ 内容区 padding 24px                      │
│ 240px    │ 页面标题 28px + 描述 14px                 │
│ 可折叠    │ 筛选卡 → 数据卡 → 表格/图表                │
│ 64px 折叠 │ 分页居右                                  │
└──────────┴─────────────────────────────────────────┘
```

- 最小宽度 1280px；1366×768 下无横向滚动。
- 表格行高 52px；操作列固定右侧；超过 3 个操作收进"更多"。
- 筛选区：一行不超过 4 个控件；"查询/重置"右对齐；回车即查询。
- 图表：卡片内边距 24px；标题左上；图例右上；无数据占位。

### 3.2 农户端（H5）

- 视口 375–428px；安全区适配（`env(safe-area-inset-bottom)`）。
- 顶部：返回 + 标题（居中）+ 帮助；底部主按钮固定，高 48px，距底 16px。
- 表单：单列；标签在输入框上方；输入框高 44px；错误文案在下方 12px 红字。
- 预约流程用**步骤条**（1 填写 → 2 选时段 → 3 确认），可返回上一步，数据不丢。
- 排队页：卡片式，顺位用大数字 + 进度条；候补倒计时醒目。

## 5. 组件规范

### 5.1 状态标签（全系统统一）

| 业务状态 | 文案 | 颜色 | 样式 |
|---|---|---|---|
| `PENDING_REVIEW` | 待审核 | 橙 | 浅橙底 + 橙字 |
| `APPROVED` | 已通过 | 绿 | 浅绿底 + 绿字 |
| `REJECTED` | 未通过 | 红 | 浅红底 + 红字 |
| `ADJUSTING` | 调整中 | 紫 | 浅紫底 + 紫字 |
| `CANCELLED` | 已取消 | 灰 | 浅灰底 + 灰字 |
| `COMPLETED` | 已完成 | 深绿 | 实心绿底 + 白字 |
| `NO_SHOW` | 未开播 | 灰红 | 浅红底 + 灰字 |
| `WAITING` | 排队中 | 紫 | 浅紫底 + 紫字 |
| `CANDIDATE` | 候补中 | 橙 | 浅橙底 + 橙字 |
| `CONFIRMED` | 已确认 | 绿 | 浅绿底 + 绿字 |
| `EXPIRED` | 已过期 | 灰 | 浅灰底 |
| `ABANDONED` | 已放弃 | 灰 | 浅灰底 |
| `CLOSED` | 已关闭 | 灰 | 浅灰底 |
| 设备 `AVAILABLE` | 可用 | 绿 | 圆点 + 文字 |
| 设备 `OCCUPIED` | 使用中 | 蓝 | 圆点 + 文字 |
| 设备 `MAINTENANCE` | 维修中 | 橙 | 圆点 + 文字 |
| 设备 `DISABLED` | 停用 | 灰 | 圆点 + 文字 |
| 农户 `CERTIFIED` | 已认证 | 绿 | 同原型 |
| 农户 `PENDING` | 待审核 | 橙 | 同原型 |
| 农户 `REJECTED` | 未通过 | 红 | 同原型 |
| 通知 `SENT` | 已发送 | 绿 | 文本 |
| 通知 `FAILED` | 发送失败 | 红 | 文本 |
| 通知 `DEAD` | 已终止 | 红 | 文本 + 重发按钮（管理员） |

**规则**：颜色不是唯一信息载体，必须带文字；同一状态在列表、详情、通知、导出中使用同一文案。

### 5.2 表格

- 表头：`#F9FAFB` 底、12px 灰字、左对齐（数字右对齐）。
- 行：悬停 `#F9FAFB`；选中 `#E8F5E9`。
- 空态：插画 + "暂无数据" + 主操作按钮。
- 加载：骨架屏（≥300ms 才显示，避免闪烁）。
- 分页：默认 20；显示总数；跳页。
- 批量操作：勾选后出现操作条，危险操作二次确认。

### 5.3 表单

| 规则 | 说明 |
|---|---|
| 标签 | 上方；必填星号 `*` 红色 |
| 校验时机 | 失焦校验 + 提交校验；不实时打断输入 |
| 错误 | 字段下方红字 + 输入框红边；滚动定位到第一个错误 |
| 帮助 | 字段下方 12px 灰字，如"精确到小时，1–4 小时" |
| 只读 | 灰底 + 锁图标 + tooltip 说明原因 |
| 危险 | 主按钮红色，需输入原因/二次确认 |
| 保存 | 提交中禁用 + loading；防重复提交 |

**关键文案**：
- 时段："请选择整点开始的时段，单场 1–4 小时，需提前 2 小时预约。"
- 冲突："该时段已被占用，可进入排队或选择其他时段。"
- 驳回："请填写至少 5 字的原因，并给出一个可预约的推荐时间。"
- 冷却："您在该设备的候补确认后取消过预约，需到 2026-10-22 15:00 后才能再次排队。"

### 5.4 弹窗与反馈

| 场景 | 形式 | 要求 |
|---|---|---|
| 审核通过 | 确认弹窗 | 展示预约摘要 + 资源，确认后 Toast |
| 驳回 | 表单弹窗 | 原因 + 推荐时间（日期时间选择器） |
| 取消预约 | 表单弹窗 | 原因下拉 + 备注；红字提示影响 |
| 删除农户 | 二次确认 + 二次验证 | 输入"删除"确认 + 动态码 |
| 候补确认 | 倒计时弹窗 | 剩余时间、资源、确认/放弃 |
| 成功 | Toast 2s | 文案含下一步，如"已提交，24 小时内审核" |
| 失败 | Toast/Inline | 含 traceId 与可行动建议 |

### 5.5 通知与提醒

- 顶栏铃铛：未读数红点（>99 显示 99+）；点击进入通知中心。
- 开播提醒：H5 首页顶部绿色横幅，含"添加日历"和"查看详情"（原型样式）。
- 候补提醒：站内 + 短信；站内卡片含倒计时与截止时间。
- 故障预警：红色横幅 + 短信；管理员端同时提示受影响预约数。

### 5.6 图表

- ECharts；主色 `#2E7D32`，辅助 `#C8A96A`、`#7C3AED`、`#F59E0B`。
- 折线：平滑、面积渐变 10%；柱状：圆角 4px。
- 坐标轴：12px 灰字；网格线 `#F3F4F6`。
- Tooltip：显示口径与数值；空数据不画空轴，显示"暂无数据"。
- 导出 PDF 时图表按 2x 渲染，保证清晰。

## 6. 关键交互设计

### 6.1 农户预约（3 步）

```text
步骤1 填写信息：县域（锁定）、主题、主推农产品（可增删，最多20）
   ↓ 下一步（本地校验）
步骤2 选择时段：日期（未来30天）→ 可用时段（整点）→ 设备/场地（推荐可用）
   ↓ 冲突时：展示"已满"并提供"进入排队"
步骤3 确认提交：摘要卡（主题/时间/资源/产品）+ 规则提示 + 提交
   ↓ 成功页：预约号 + 审核时限 + "查看我的预约"
```

- 每步可返回，数据保留（sessionStorage）。
- 步骤 2 只展示可用资源，不可用置灰并注明"维修中/已占用"。
- 提交按钮防抖；成功后禁用返回，避免重复提交（幂等兜底）。

### 6.2 排队状态页（对应原型）

- 顶部三张统计卡：当前排队中、候补状态、今日直播。
- 今日直播横幅：主题、编号、时间、场地、添加日历、查看详情。
- 列表卡片：预约时间、预计开始、优先级（仅展示）、顺位进度条 `N/总数`。
- 候补卡片：候补顺位、期望直播时间、候补有效期、倒计时。
- 空态："暂无排队，去看看可预约时段"。
- 顺位变化：数字动画 + Toast"您的顺位已更新为第 2 位"。

### 6.3 候补确认弹窗

- 标题："您有一个候补名额待确认"
- 内容：直播主题、时间、场地、截止时间（精确到分钟）、倒计时。
- 按钮："确认预约"（主）/ "放弃机会"（次，需选原因）。
- 超时：自动关闭 + 提示"已超时，名额顺延给下一位"。

### 6.4 审核工作台

- 左侧列表（待审核优先），右侧详情；支持键盘 `J/K` 切换、`A` 通过、`R` 驳回（管理员效率）。
- 通过：一键确认，展示资源占用结果。
- 驳回：原因快捷标签（资质不清/主题不符/资源冲突/其他）+ 推荐时间。
- 审核后自动跳下一条，Toast 可撤销 3 秒（仅限误操作，后端需支持撤回？V1 不做撤回，改为二次确认）。

## 7. 响应式与兼容

| 端 | 断点 | 要求 |
|---|---|---|
| 管理端 | ≥1280px | 完整布局；1366×768 无横向滚动 |
| 管理端 | 1024–1279 | 侧边栏折叠；表格横向滚动 |
| H5 | 375–428px | 单列；底部按钮固定；安全区 |
| H5 | 320–374px | 字号不缩小，允许纵向滚动；按钮全宽 |
| 平板 | 768–1024 | 管理端可用；H5 居中最大 480px |

浏览器：Chrome/Edge/Firefox 最近 2 个大版本；iOS Safari 15+；Android Chrome 100+。
**不支持**：IE、微信内置浏览器的极旧内核（提示升级）。

## 8. 可访问性（A11y）

- 对比度：正文 ≥4.5:1，大字 ≥3:1；主色按钮白字对比度已验证。
- 焦点：可见 2px 主色 outline；Tab 顺序符合视觉顺序。
- 语义：表单 `label` 关联；表格 `caption`；图标按钮有 `aria-label`。
- 状态：不只靠颜色，配文字/图标。
- 触控：≥44×44px；相邻可点区域间距 ≥8px。
- 动态：Toast 用 `aria-live="polite"`；错误摘要可聚焦。
- 缩放：200% 不截断关键操作。

## 9. 文案规范

| 场景 | 推荐 | 避免 |
|---|---|---|
| 提交 | 提交预约 | 立即申请 |
| 审核不通过 | 本次未通过 | 驳回/拒绝（对农户过硬） |
| 候补 | 候补名额 | 替补资格 |
| 排队 | 进入排队 | 加入等待队列 |
| 错误 | 该时段已被占用，可进入排队或选择其他时段 | 资源冲突 409 |
| 空态 | 暂无预约，去约一场直播吧 | No Data |
