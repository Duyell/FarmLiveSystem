## 1. 通用约定

### 1.1 请求格式

- 请求体：JSON，`Content-Type: application/json`
- 时间：`yyyy-MM-dd HH:mm:ss`
- 日期：`yyyy-MM-dd`
- 时间时段：`HH:mm`
- 分页：`page` 从 1 开始，`size` 默认 10

### 1.2 响应格式

成功：

```json
{
  "code": "OK",
  "message": "成功",
  "data": {}
}
```

失败：

```json
{
  "code": "BAD_REQUEST",
  "message": "用户名已存在",
  "data": null
}
```

### 1.3 状态码

| HTTP | code | 含义 |
|---|---|---|
| 200 | OK | 成功 |
| 400 | BAD_REQUEST | 参数错误、业务校验失败 |
| 401 | UNAUTHORIZED | 未登录或令牌失效 |
| 403 | FORBIDDEN | 无权限 |
| 404 | NOT_FOUND | 数据不存在 |
| 409 | CONFLICT | 唯一约束冲突、状态冲突 |
| 500 | SERVER_ERROR | 服务器异常 |

### 1.4 分页响应

```json
{
  "code": "OK",
  "message": "成功",
  "data": {
    "items": [],
    "total": 0,
    "page": 1,
    "size": 10
  }
}
```

## 2. 登录与当前用户

### 2.1 健康检查

`GET /api/health`，不需要登录。

响应：

```json
{"code":"OK","message":"成功","data":{"status":"UP"}}
```

### 2.2 登录

`POST /api/auth/login`

请求：

```json
{
  "username": "admin",
  "password": "Admin@123"
}
```

响应：

```json
{
  "code": "OK",
  "message": "成功",
  "data": {
    "token": "8f3c...",
    "user": {
      "id": 1,
      "username": "admin",
      "displayName": "系统管理员",
      "roleCode": "system_admin",
      "roleName": "系统管理员",
      "mustChangePassword": true
    }
  }
}
```

失败：401 `UNAUTHORIZED`，提示“用户名或密码错误”。

### 2.3 当前用户

`GET /api/auth/me`

响应：

```json
{
  "code": "OK",
  "message": "成功",
  "data": {
    "id": 1,
    "username": "admin",
    "displayName": "系统管理员",
    "roleCode": "system_admin",
    "roleName": "系统管理员",
    "mustChangePassword": false
  }
}
```

### 2.4 修改密码

`POST /api/auth/change-password`

请求：

```json
{
  "oldPassword": "Admin@123",
  "newPassword": "NewPass@123"
}
```

规则：

- 新密码至少 8 位，包含字母和数字；
- 修改成功后 `mustChangePassword` 变为 0；
- 旧密码错误返回 400。

### 2.5 退出登录

`POST /api/auth/logout`

- 服务端使当前令牌失效；
- 前端清除本地令牌。

## 3. 系统管理员接口

以下接口要求 `system_admin` 角色。

### 3.1 工作台

`GET /api/admin/dashboard`

响应：

```json
{
  "code": "OK",
  "message": "成功",
  "data": {
    "accounts": 5,
    "farmers": 20,
    "venues": 5,
    "devices": 10,
    "bookings": 50
  }
}
```

### 3.2 角色列表

`GET /api/admin/roles`

响应：

```json
{
  "code": "OK",
  "message": "成功",
  "data": [
    {"id":1,"code":"system_admin","name":"系统管理员"},
    {"id":2,"code":"live_admin","name":"直播管理员"},
    {"id":3,"code":"farmer","name":"农户"},
    {"id":4,"code":"data_viewer","name":"数据统计员"}
  ]
}
```

### 3.3 账号列表

`GET /api/admin/accounts?keyword=&page=1&size=10`

响应：

```json
{
  "code": "OK",
  "message": "成功",
  "data": {
    "items": [
      {
        "id": 1,
        "username": "admin",
        "displayName": "系统管理员",
        "roleId": 1,
        "roleCode": "system_admin",
        "roleName": "系统管理员",
        "farmerId": null,
        "farmerName": null,
        "status": "active",
        "mustChangePassword": false,
        "lastLoginAt": "2026-10-19 23:00:00",
        "createdAt": "2026-10-19 20:00:00"
      }
    ],
    "total": 1,
    "page": 1,
    "size": 10
  }
}
```

### 3.4 新增账号

`POST /api/admin/accounts`

请求：

```json
{
  "username": "liveadmin",
  "password": "Live@123",
  "displayName": "直播管理员",
  "roleId": 2,
  "farmerId": null,
  "status": "active"
}
```

规则：

- 用户名唯一；
- 密码至少 8 位，包含字母和数字；
- 角色必须存在；
- 角色为 `farmer` 时必须关联农户；
- 非农户角色 `farmerId` 必须为空；
- 新账号 `mustChangePassword` 默认 1。

### 3.5 修改账号

`PUT /api/admin/accounts/{id}`

请求：

```json
{
  "displayName": "直播管理员甲",
  "roleId": 2,
  "farmerId": null,
  "status": "active"
}
```

规则：

- 不能把自己改成停用；
- 不能删除或停用最后一个系统管理员；
- 用户名不在这里修改。

### 3.6 删除账号

`DELETE /api/admin/accounts/{id}`

规则：

- 不能删除自己；
- 不能删除最后一个系统管理员；
- 农户账号删除后，农户档案保留。

### 3.7 重置密码

`POST /api/admin/accounts/{id}/reset-password`

请求：

```json
{"newPassword":"Reset@123"}
```

规则：

- 新密码至少 8 位，包含字母和数字；
- 重置后 `mustChangePassword` 变为 1。

### 3.8 农户列表

`GET /api/admin/farmers?keyword=&page=1&size=10`

响应项：

```json
{
  "id": 1,
  "farmerNo": "NF2026001",
  "name": "张农户",
  "county": "寿县",
  "phone": "138****0001",
  "qualificationStatus": "verified",
  "status": "active",
  "createdAt": "2026-10-19 20:00:00"
}
```

### 3.9 新增农户

`POST /api/admin/farmers`

```json
{
  "farmerNo": "NF2026003",
  "name": "王农户",
  "county": "寿县",
  "phone": "13800000003",
  "qualificationStatus": "pending",
  "status": "active"
}
```

规则：

- 农户编号唯一；
- 手机号 11 位；
- 不接收身份证号、家庭住址字段。

### 3.10 修改农户

`PUT /api/admin/farmers/{id}`

```json
{
  "name": "王农户",
  "county": "寿县",
  "phone": "13800000003",
  "qualificationStatus": "verified",
  "status": "active"
}
```

### 3.11 删除农户

`DELETE /api/admin/farmers/{id}`

规则：有账号或预约关联时不能删除，返回 409。

### 3.12 场地列表

`GET /api/admin/venues?keyword=&page=1&size=10`

```json
{
  "id": 1,
  "venueNo": "C001",
  "name": "一号直播间",
  "location": "寿县电商中心一楼",
  "capacity": 20,
  "openStart": "08:00",
  "openEnd": "20:00",
  "status": "available"
}
```

### 3.13 新增/修改/删除场地

- `POST /api/admin/venues`
- `PUT /api/admin/venues/{id}`
- `DELETE /api/admin/venues/{id}`

请求：

```json
{
  "venueNo": "C003",
  "name": "三号直播间",
  "location": "寿县电商中心三楼",
  "capacity": 15,
  "openStart": "09:00",
  "openEnd": "18:00",
  "status": "available"
}
```

规则：场地编号唯一；有设备关联时不能删除。

### 3.14 设备列表

`GET /api/admin/devices?keyword=&page=1&size=10`

```json
{
  "id": 1,
  "deviceNo": "ZB-C001-01",
  "name": "主摄像机",
  "model": "CAM-4K",
  "venueId": 1,
  "venueName": "一号直播间",
  "status": "available",
  "calibrationDate": "2026-12-31"
}
```

### 3.15 新增/修改/删除设备

- `POST /api/admin/devices`
- `PUT /api/admin/devices/{id}`
- `DELETE /api/admin/devices/{id}`

请求：

```json
{
  "deviceNo": "ZB-C001-03",
  "name": "补光灯",
  "model": "LIGHT-200",
  "venueId": 1,
  "status": "available",
  "calibrationDate": "2026-12-31"
}
```

规则：

- 设备编号唯一；
- 所属场地必须存在；
- 设备编号建议按 `ZB-场地编号-序号`；
- 有预约关联时不能删除。

## 6. 常见错误

| 场景 | HTTP | code | 提示 |
|---|---|---|---|
| 未带令牌 | 401 | UNAUTHORIZED | 请先登录 |
| 令牌过期 | 401 | UNAUTHORIZED | 登录已过期，请重新登录 |
| 非系统管理员访问管理接口 | 403 | FORBIDDEN | 没有权限 |
| 用户名重复 | 409 | CONFLICT | 用户名已存在 |
| 删除有设备的场地 | 409 | CONFLICT | 该场地下还有设备，不能删除 |
| 参数为空 | 400 | BAD_REQUEST | 具体字段提示 |
