## 1. 目的与判定标准

统一全站视觉与交互，使新增页面不引入新的色值、字号和断点即可完成。

**合格判定**：任取两个不同角色的页面并排，容器、间距、按钮、状态标签、字号层次一致。

---

## 2. 设计原则

1. **一页一件事**——每个页面一个白卡片，承载一个业务动作。
2. **骨架复用**——所有页面归入列表页、表单页、状态页三类骨架，不另起样式。
3. **状态双编码**——状态同时用颜色和文字表达，不依赖颜色单独传达。
4. **颜色只做语义**——大面积中性色，品牌绿限用于导航、主操作和关键强调。
5. **移动端可用**——手机网页保证"能完成"，不追求与桌面一致的信息密度。

| 品牌深绿 | `#245f27` | 侧栏渐变终点           | `MainLayout.vue`                 |
| 标题绿  | `#1f3b25` | 页头标题、统计数值、选中菜单文字 | 布局与各页面                           |
| 选中底  | `#eaf4ea` | 当前菜单项背景          | `MainLayout.vue`                 |




### 3.2 中性色


| 令牌    | 色值        | 用途            |
| ----- | --------- | ------------- |
| 页面底色  | `#f4f6f8` | `body` 背景     |
| 内容区底色 | `#f5f7fa` | 主内容区背景        |
| 卡片底   | `#ffffff` | 所有卡片          |
| 正文色   | `#1f2d3d` | 默认文字          |
| 辅助色   | `#7a8699` | 副标题、字段说明、次要信息 |
| 分隔线   | `#eef1f4` | 页头下边框         |




### 3.3 语义色

沿用 Element Plus 语义色，用于标签与提示：


| 语义   | 色值        | 用于             |
| ---- | --------- | -------------- |
| 成功   | `#67c23a` | 已认证、已通过、启用、已送达 |
| 警告   | `#e6a23c` | 待审核、重试中        |
| 危险   | `#f56c6c` | 未通过、已驳回、发送失败   |
| 信息   | `#909399` | 停用、已关闭、已取消     |
| 数值警示 | `#ff7d00` | 页面内超阈值的统计数值    |




### 3.4 使用规则

- 品牌绿**不做**大面积背景，不进表格行、不进正文。
- 一个屏幕内主操作按钮只用一处主色。
- 语义色只表达状态，不用于装饰。

## 6. 布局规范

```text
┌──────────────┬────────────────────────────────────┐
│ 侧栏 232px    │ 页头 68px：标题 + 副标题 + 通知角标    │
│ 品牌区 64px   ├────────────────────────────────────┤
│ 用户卡片      │ 内容区 padding 22px，仅纵向滚动        │
│ 菜单分组      │ ┌────────────────────────────────┐ │
│ 菜单项 44px   │ │ 页面卡片：工具栏 + 表格/表单      │ │
│ 退出登录      │ └────────────────────────────────┘ │
└──────────────┴────────────────────────────────────┘
```


| 区域   | 规格                                             |
| ---- | ---------------------------------------------- |
| 侧栏   | 232px 固定，绿色渐变背景，白色文字                           |
| 品牌区  | 高 64px，标识块 30×30 圆角 8                          |
| 用户卡片 | 半透明白底 12%，圆角 10，头像 36×36                       |
| 菜单项  | 高 44px，圆角 8，未选中 78% 白，选中 `#eaf4ea` + `#1f3b25` |
| 页头   | 高 68px，白底，下边框 `#eef1f4`，左右 24px                |

**规则**：侧栏固定、内容区独立滚动；页头承载页面身份，内容区不重复大标题。

## 7. 组件规范



### 7.1 页面容器

`.page-card`：白底、圆角 10、内边距 18、卡片阴影。所有业务页面外层必须是它，不直接铺在内容区背景上。

### 7.2 工具栏

`.page-toolbar`：横向排列，`gap:10px`，自动换行，下间距 14px。
顺序固定为**搜索 → 筛选 → 已选条件标签 → 主操作按钮（最右）**。

### 7.3 表格与分页

- 列顺序：标识列 → 业务列 → 状态列 → 时间列 → 操作列（最右）。
- 状态列一律用标签，不用纯文字。
- 长文本列优先压缩，不出现横向滚动。
- 分页显示总数与页码，手机端不隐藏分页。



### 7.4 表单

- 标签在上（`label-position="top"`）。
- 必填项用红色星号，**不写**"必填"二字。
- 占位符给真实示例（如"XX县草莓采摘专场"），不用"请输入"。
- 字段下方一行灰字说明格式（如"多个产品用'、'分隔，需注明规格"）。
- 提交前前端校验，错误用消息提示，不弹窗打断。



### 7.5 状态标签

统一用 `el-tag`，按第 3.3 节语义色映射。标签文字用**业务状态原词**，不做同义改写。

### 7.6 统计卡

白底、圆角 10、内边距 18、阴影见第 5 节；左侧图标块 44×44 圆角 10，图标色品牌绿；标签 13px 辅助色；数值 24px 加粗、标题绿。

### 7.7 弹窗与确认

- 破坏性操作（删除、驳回、关闭队列、取消预约）必须二次确认，文案写清后果。
- 弹窗最大宽度 `calc(100vw - 24px)`，手机端不超出屏幕。



### 7.8 空态与加载

- 无数据给提示文案，不留白屏。
- 请求期间使用加载态；提交按钮同时置为禁用，防重复提交。



### 7.9 消息提示

操作结果用轻提示（`ElMessage`），失败必须说明原因；不使用 alert。

### 7.10 登录页

单卡居中，品牌标识 + 标题 + 副标题；输入框大尺寸；验证码与输入同一行，按钮不换行；主按钮占满宽度、品牌绿；手机端卡片宽度自适应，内边距收窄。

## 8. 响应式规范


| 断点       | 触发        | 主要变化                                                                                           |
| -------- | --------- | ---------------------------------------------------------------------------------------------- |
| `≤768px` | 平板 / 手机横屏 | 侧栏转顶部横排、菜单横向滚动、隐藏用户卡与菜单分组；页头自适应高度；内容区 padding 22→12；筛选控件整行；统计卡 4 列→2 列；表格字号 14→12；弹窗锁宽度；登录卡自适应 |
| `≤420px` | 手机竖屏      | 统计卡降为 1 列；隐藏横向滚动条                                                                              |


**验收口径**：在 375、390、428 三个宽度下，页面无横向滚动，核心操作可完成。

---



## 9. 交互与反馈


| 场景   | 规则                      |
| ---- | ----------------------- |
| 提交中  | 按钮 loading 且禁用，禁止重复点击   |
| 操作成功 | 轻提示 + 列表刷新，不跳页          |
| 操作失败 | 轻提示说明原因，保留用户输入          |
| 登录失效 | 统一跳转登录页，不在原页报错          |
| 危险操作 | 二次确认，确认按钮用危险色           |
| 权限不足 | 隐藏入口；接口返回 403 时给"无权限"提示 |


---



## 10. 权限与界面

菜单按角色下发，不写死在页面里。


| 角色    | 菜单数 | 差异要点        |
| ----- | --- | ----------- |
| 系统管理员 | 11  | 独有账号权限、操作日志 |
| 直播管理员 | 8   | 无账号权限、无操作日志 |
| 农户    | 6   | 全部为 C 端入口   |
| 数据统计员 | 3   | 仅统计、通知、帮助   |


**原则**：前端隐藏菜单和按钮只是入口控制，权限边界由后端接口校验保证。

---



## 11. 文案规范

- 同一功能全站一个名称，不出现同义词混用。
- 页头标题与菜单名一致。
- 按钮用动词短语（"提交预约""通过审核"），不用"确定/好的"。
- 时间、数量带单位；金额、百分比保留统一精度。
