# 角色任务分工

## 项目负责人

### 职责定位

对项目目标、范围、计划、风险和验收负责，协调五类角色按同一目标推进。

### 负责事项

| 任务 | 具体工作 | 交付物 |
|---|---|---|
| 项目计划 | 拆分阶段任务，明确负责人、依赖和时间节点 | 项目计划、任务清单 |
| 范围管理 | 确认需求边界，处理需求变更，避免开发范围失控 | 需求清单、变更记录 |
| 需求管理 | 收集需求，组织需求确认，明确验收标准 | 需求说明、验收标准 |
| 进度管理 | 跟踪各角色进度，发现延期和阻塞 | 进度记录、问题清单 |
| 风险管理 | 识别技术、测试、部署和协作风险，明确应对人 | 风险清单 |
| 跨角色协调 | 处理前后端接口、设计、测试、运维之间的协作问题 | 会议结论、任务单 |
| 验收组织 | 组织功能演示、缺陷复盘和阶段验收 | 验收记录、问题闭环表 |
| 交付管理 | 汇总代码、数据库脚本、文档、演示数据和账号 | 交付包 |
| 复盘改进 | 汇总项目问题，形成后续改进项 | 项目复盘 |

### 协作边界

- 不代替后端写业务代码；
- 不代替前端实现页面；
- 不代替测试出具测试结论；
- 不绕过 UI/UX 直接决定视觉细节；
- 对需求歧义和范围变更做最终确认。

## 后端开发

### 职责定位

负责技术架构、数据库、接口和核心业务逻辑，保证系统数据正确、接口稳定、权限可控。

### 负责事项

| 任务 | 具体工作 | 交付物 |
|---|---|---|
| 技术架构 | 维护后端技术栈、分层结构和技术规范 | 架构说明、技术决策记录 |
| 数据库设计 | 设计表结构、索引、外键和迁移脚本 | 数据库设计、`init.sql`、迁移脚本 |
| 登录认证 | 登录、验证码、失败锁定、改密、令牌校验 | 认证接口与规则 |
| 权限控制 | 四类角色的接口权限和数据范围控制 | 权限拦截规则 |
| 区域字典 | 省/市/区县数据维护和查询接口 | 区域数据、区域接口 |
| 基础数据 | 农户、场地、设备组合、资质、账号的增删改查 | 基础数据接口 |
| 预约业务 | 预约提交、冲突校验、审核、取消、完成 | 预约接口 |
| 预约调整 | 调整申请、审批、资源切换 | 调整接口 |
| 排队候补 | 排队、顺位、候补确认、超时、关闭 | 排队接口 |
| 通知服务 | 审核、排队、候补、调整、设备故障、恢复通知 | 通知接口、模板 |
| 销售统计 | 销售录入、统计指标、趋势、导出、农户统计 | 统计接口 |
| 设备故障 | 报修、维修完成、受影响预约处理、恢复 | 故障接口 |
| 操作日志 | 关键业务操作写入审计日志 | 日志接口 |
| 接口文档 | 维护接口路径、参数、权限、错误码 | 接口文档 |
| 技术支持 | 为前端、测试、运维提供接口、日志和部署支持 | 技术支持记录 |

### 协作边界

- 与前端确认接口字段、错误码和联调环境；
- 为测试提供测试数据、日志和问题定位支持；
- 为运维提供数据库、端口、上传目录等部署参数；
- 数据库结构变更必须同步迁移脚本和接口文档。

## 前端开发

### 职责定位

负责 Web 页面、交互实现和接口联调，保证不同角色能正确、顺畅地完成业务操作。

### 负责事项

| 任务 | 具体工作 | 交付物 |
|---|---|---|
| 登录与路由 | 登录页、验证码、改密、角色首页和路由守卫 | 页面与路由 |
| 主布局 | 侧边菜单、顶部栏、角色菜单和页面容器 | 布局组件 |
| 基础数据页面 | 农户、场地、设备组合、资质、账号管理 | 管理页面 |
| 区域选择 | 省/市/区县三级联动、回显和筛选用 | 区域组件 |
| 预约页面 | 农户提交预约、我的预约、预约审核、预约调整 | 预约页面 |
| 排队页面 | 排队状态、顺位、候补确认、放弃、关闭 | 排队页面 |
| 通知页面 | 我的通知、通知管理、模板维护、短信重试 | 通知页面 |
| 销售统计 | 销售录入、统计筛选、趋势、明细、导出 | 统计页面 |
| 农户统计 | 本人完成场次和卖出数量 | 农户数据页面 |
| 设备故障 | 报修、维修完成、故障历史和组合配置 | 故障弹窗与页面 |
| 工作台 | 待审核、今日直播、可用资源 | 工作台页面 |
| 权限展示 | 按角色隐藏菜单和按钮，限制敏感明细展示 | 页面权限规则 |
| 接口联调 | 请求参数、响应处理、loading、空态、错误提示 | 联调完成页面 |
| 响应式 | 桌面和手机宽度适配，避免横向滚动 | 适配样式 |
| 前端质量 | 自测、构建、类型检查、公共组件维护 | 构建通过的前端代码 |

### 协作边界

- 按 UI/UX 设计稿和交互说明实现；
- 接口字段以接口文档和后端确认为准；
- 页面权限只是入口控制，不能替代后端权限校验；
- 测试反馈的前端缺陷由前端修复并回归。

## 测试与运维

### 职责定位

负责测试验证、质量结论、环境部署、备份恢复和运行保障。

### 负责事项

| 任务 | 具体工作 | 交付物 |
|---|---|---|
| 测试计划 | 明确测试范围、环境、数据、轮次和退出标准 | 测试计划 |
| 测试用例 | 设计功能、权限、异常、边界、兼容性用例 | 测试用例 |
| 权限测试 | 四类角色登录、越权访问、隐私限制 | 权限测试记录 |
| 功能测试 | 基础数据、预约、调整、排队、通知、销售、统计、故障 | 功能测试记录 |
| 并发测试 | 同一场地同一时段并发预约、并发排队 | 并发测试记录 |
| 边界测试 | 24 小时截止、72 小时冷却、跨天、非整点 | 边界测试记录 |
| 兼容性测试 | 桌面主流宽度、手机 375–428 | 兼容性记录 |
| 缺陷管理 | 提交、跟踪、复测、关闭缺陷 | 缺陷清单 |
| 回归测试 | 缺陷修复后执行主流程回归 | 回归记录 |
| 测试报告 | 汇总测试结果、风险和遗留问题 | 测试报告 |
| 环境部署 | MySQL、后端、前端环境和启动配置 | 部署手册 |
| 版本发布 | 构建产物、数据库迁移、发布步骤 | 发布记录 |
| 数据备份 | 定期备份数据库和上传文件 | 备份文件与脚本 |
| 恢复演练 | 从备份恢复并验证主流程 | 恢复记录 |
| 运行监控 | 端口、健康检查、日志、磁盘和资源监控 | 监控清单 |
| 故障处理 | 连接失败、端口冲突、迁移失败等常见问题处理 | 故障处理记录 |

### 协作边界

- 测试环境和测试数据由测试与运维准备；
- 缺陷由对应开发修复，测试负责复测关闭；
- 部署参数由后端提供，前端提供构建产物；
- 备份和恢复演练结果向项目负责人反馈。

## UI/UX 设计师与文档管理

### 职责定位

负责产品视觉、交互、响应式设计和文档管理，保证页面一致、易用、可交付。

### 负责事项

| 任务 | 具体工作 | 交付物 |
|---|---|---|
| 设计规范 | 颜色、字体、间距、卡片、表格、按钮、标签规范 | 设计规范 |
| 页面设计 | 登录、工作台、列表、表单、弹窗、空态、错误态 | 页面设计稿 |
| 交互设计 | 预约、审核、排队、候补、调整、设备故障流程 | 交互说明 |
| 响应式设计 | 桌面和手机 375–428 布局规则 | 响应式设计说明 |
| 设计走查 | 对照实现检查视觉、交互和文案 | 走查记录 |
| 可用性优化 | 减少误操作，完善确认、提示和反馈 | 优化清单 |
| 文档规范 | 文档分类、命名、版本和状态规则 | 文档规范 |
| 文档收集 | 收集需求、设计、接口、测试、部署文档 | 文档清单 |
| 版本管理 | 维护文档变更、废弃标记和归档 | 版本记录 |
| 文档分发 | 按角色分发文档，解答文档使用问题 | 文档包 |
| 成果归档 | 归档设计稿、截图、文档和交付材料 | 归档记录 |

### 协作边界

- 设计稿和交互说明交付给前端实现；
- 设计走查问题由前端修复，UI/UX 复看；
- 文档版本与代码、数据库脚本保持一致；
- 不直接用设计稿替代需求文档和接口文档。

## 跨角色交接规则

| 交接点 | 交出方 | 接收方 | 交接内容 |
|---|---|---|---|
| 需求确认 | 项目负责人 | 全体 | 需求范围、优先级、验收标准 |
| 接口确认 | 后端开发 | 前端开发、测试与运维 | 接口字段、错误码、测试数据 |
| 设计确认 | UI/UX | 前端开发 | 页面稿、交互说明、响应式规则 |
| 提测 | 前端开发、后端开发 | 测试与运维 | 可运行版本、变更说明、测试账号 |
| 缺陷修复 | 对应开发 | 测试与运维 | 修复说明、影响范围 |
| 部署交付 | 测试与运维 | 项目负责人 | 部署记录、备份记录、运行状态 |
| 验收交付 | 项目负责人 | 全体 | 验收结论、遗留问题、交付包 |
