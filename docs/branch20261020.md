# 20261020 开发总结

> 对应分支：`branch20261020-1`（区域 + 预约 + 排队）、`branch20261020-2`（通知）
> 基线：main（登录 + 系统管理员 CRUD）

## 一、今日完成内容

### 1. 区域字典（开发计划任务 16–18，branch20261020-1）

- 新增区域查询接口 `GET /api/regions?parentCode=`：不传参数返回省级，传省/市编码逐级返回市/县，只返回启用区域，按编码排序；
- 农户、场地接口全面支持 `countyCode`：新增/修改必填（校验必须是启用中的县级区域），`county` 文本由后端按编码回写为显示快照，防止前端伪造；
- 农户、场地列表支持按 `countyCode` 精确筛选；
- 前端新增 `RegionSelect` 省市区三级级联组件，接入农户、场地页面（表单 + 筛选）；
- 数据库无结构变更（复用已有 `region` 表与 `county_code` 列）。

### 2. 预约模块（预约-02 ~ 05，branch20261020-1）

- 农户提交预约：时段整点、1–4 小时、不跨天、最早提前 2 小时、最多提前 30 天；
- 冲突校验：同一场地同一时段只成功一场（提交时按预约表校验 + 审核通过时写小时级 `resource_lock` 资源锁双保险）；
- 直播管理员审核：通过锁资源，驳回需至少 5 字意见 + 推荐时间；重复审核返回 409；
- 我的预约列表、取消（开播前 24 小时内不可取消，`CANCEL_WINDOW_CLOSED`）；
- 可用资源查询 `GET /api/resources/available`（按时段排除被占场地/设备，供预约表单联动）；
- 登录支持 `roleCode` 角色校验，选错角色返回 403；拦截器按路径控制 `/api/farmer/**`、`/api/live/**` 角色。

### 3. 排队与候补（排队-01 ~ 04，branch20261020-1）

- 按场地 + 时段排队，**时段必须已被他人预约占用**才能加入（空闲直接预约、自己占用不可排队）；
- 校验：同一农户同一时段仅一个有效排队、开播前 24 小时内不可加入、候补确认后又取消 72 小时冷却；
- 排队号 `Q-农户编号-日期-序号`；顺位、总人数、预计等待；
- 晋升机制：预约取消释放场地时，若该时段无其他有效预约且场内至少 1 台可用设备且早于开播 24 小时，队首自动升级候补；
- 候补确认：自动分配可用设备并生成 `approved` 预约 + 资源锁；无设备返回 409、资格保留；
- 放弃 / 超时（候选截止 = 开播前 1 小时，每分钟扫描）自动顺延下一位；
- 直播管理员可查看分组队列并一键关闭整个队列组；
- 数据库：`queue_ticket` 补 `slot_end` 列（增量脚本 `003-queue-slot-end.sql`）。

### 4. 通知模块（通知-01 ~ 03，branch20261020-2）

- 五类事件全部接入：审核结果（review）、候补晋升（candidate）、顺位变化（queue）、开播前 1 小时提醒（reminder）、设备故障（device_fault）；
- 双渠道分别记状态：站内即时送达（兜底）+ 短信模拟网关；短信失败按 1/5/15 分钟重试三次后最终失败，支持直播管理员手动重试；
- 开播提醒由调度每分钟扫描，同一预约只提醒一次（幂等）；
- 通知模板表 + 6 个种子模板，模板变量白名单校验，变量缺失/不支持返回 400 不发送半截内容；
- 我的通知按事件合并展示（`event_key` 关联双渠道），行内显示短信送达状态，支持标记已读；
- 顶栏铃铛显示真实未读数（接口 `GET /api/notifications/unread-count`），可点击跳转，路由切换自动刷新；
- 数据库：`notification` 补 `next_retry_at`/`read_at`/`event_key`，新建 `notification_template` 表（增量脚本 `004`、`005`）。

### 5. 前端整体改版（branch20261020-1 / -2）

- 登录页：竖排角色选择器（系统管理员/直播管理员/农户/数据统计员），登录后按角色跳转对应端；
- 绿色侧边栏布局（参考原型）：品牌区、用户信息卡、按角色生成的菜单、退出登录；未实现模块指向"建设中"空状态页；
- 基础信息管理合并为 tabs 页（农户/场地/设备）；
- 新页面：预约提交（县域→场地/设备→时段→农产品清单）、我的预约（统计卡 + 列表 + 取消）、直播管理员预约审核、我的排队（时段状态查询 + 顺位卡片）、队列管理、我的通知、发送记录与模板管理；
- 预约提交冲突时引导去排队页。

## 二、修复的缺陷

| 缺陷 | 原因 | 修复 |
|---|---|---|
| 选任意时段提示"时间格式不正确" | 可用资源接口时间拼接重复追加 `:00` | 去除重复拼接 |
| 场地/设备下拉为空 | 级联选择输出路径数组而非县编码 | `emitPath: false` |
| 农户可对自己占用的时段排队 | 缺少占用者校验 | 新增 `QUEUE_SELF_OCCUPIED` 校验 + 时段状态查询接口 |
| 我的通知同一事件显示两条 | 双渠道记录未合并 | `event_key` 关联，站内展示 + 短信状态列 |
| 铃铛角标固定为 1 且不可点 | 占位实现 | 真实未读数接口 + 点击跳转 + 路由刷新 |
