## 2. 预约调整

### 2.1 提交调整申请

- **谁用**：农户。
- **做什么**：对已通过的预约申请改时间、改场地、换设备或改农产品清单，填写原因。
- **输入/输出**：输入原预约、调整后的时段、场地、设备、农产品清单、原因；输出调整申请号和“待审批”状态。
- **规则与异常**：只能在开播前 24 小时之前申请；同一预约同时只能有一条待审批调整；审批期间原预约保持“已通过”；调整后的设备必须属于调整后的场地；调整后的时段不能和已有占用冲突；县域不能改。
- **验收标准**：开播前 24 小时内申请被拒绝；同一预约第二条待审批申请被拒绝；设备与场地不匹配被拒绝；新时段冲突被拒绝；提交后原预约状态仍是“已通过”；农户能在“我的预约”看到调整申请。
- **分级/阶段**：中 / 第二阶段。

### 2.2 审批调整

- **谁用**：直播管理员。
- **做什么**：查看调整申请，选择通过或驳回。
- **输入/输出**：输入审批结果、驳回原因；输出调整申请状态和预约结果。
- **规则与异常**：只改农产品清单、不改时段、场地、设备时，不重新锁定资源；改时段、场地或设备时，先锁定新资源，再释放旧资源；新资源锁定失败时审批失败，原预约不变；预约状态仍是“已通过”；驳回必须填原因，原预约不变；同一申请不能重复审批；审批要记操作日志。
- **验收标准**：通过后预约换到新时段、新场地、新设备；原场地和设备释放后可再预约；只改农产品清单时能通过，场地设备不变；新资源冲突时审批失败且原预约不变；驳回后原预约完全不变；驳回不填原因被拒绝；重复审批被拒绝；审批有日志。
- **分级/阶段**：中 / 第二阶段。

### 2.3 撤销调整与通知

- **谁用**：农户撤销，系统通知。
- **做什么**：农户在审批前可以撤销调整；提交、通过、驳回、撤销都发通知。
- **输入/输出**：输入撤销操作；输出“已撤销”状态和通知记录。
- **规则与异常**：只有“待审批”能撤销；已通过或已驳回不能撤销；撤销后原预约不变；四类结果都要通知农户。
- **验收标准**：待审批能撤销；已通过不能撤销；撤销后原预约仍是“已通过”；提交、通过、驳回、撤销都能在通知里看到。
- **分级/阶段**：中 / 第二阶段。

## 3. 数据统计

### 3.1 直播销售录入

- **谁用**：直播管理员。
- **做什么**：直播结束后，按场次录入或导入卖出的农产品名称、规格、数量、单位。
- **输入/输出**：输入预约号、农产品名称、规格、数量、单位；输出直播销售记录。
- **规则与异常**：只有“已完成”的直播能录入；数量必须大于 0；单位必填；同一场直播同一农产品可以分规格录多条；修改要填原因并记日志；导入失败要指出第几行错。
- **验收标准**：未完成直播不能录入；数量为 0 或负数被拒绝；单位为空被拒绝；修改有日志；导入错误能定位到行；汇总数和明细一致。
- **分级/阶段**：中 / 第二阶段。

### 3.2 四项核心指标

- **谁用**：直播管理员、数据统计员。
- **做什么**：统计场地占用率、直播场次、每场直播卖出的农产品数量、预约成功率。
- **输入/输出**：输入时间范围、县域、场地、农产品类型；输出四项指标和明细。
- **规则与异常**：
  - 场地占用率 = 已占用场地小时 ÷ 可开放场地小时 × 100%；已占用按“已通过 + 已完成”的预约小时算；可开放按场地开放时段内、场地状态正常的小时算；设备维修不影响这个分母。
  - 直播场次只算“已完成”，未开播不算。
  - 每场直播卖出的农产品数量，按直播管理员录入或导入的销售记录汇总；系统不自动抓取订单。
  - 预约成功率 =（已通过 + 已完成）÷ 提交预约数 × 100%；提交预约数不含排队记录，驳回和取消仍计入分母。
- **验收标准**：四项指标都能按明细复算；场地占用率抽样复算一致（例：开放 10 小时、被占 6 小时 = 60%）；直播场次只算已完成；销售数量与录入明细一致；预约成功率按公式复算一致；没有数据时显示 0 或“暂无”。
- **分级/阶段**：中 / 第二阶段。

### 3.3 筛选、明细与导出

- **谁用**：直播管理员、数据统计员。
- **做什么**：按时间、县域、场地、农产品类型筛选，查看明细，导出表格。
- **输入/输出**：输入筛选条件；输出指标卡、明细列表、表格文件。
- **规则与异常**：筛选条件变化后指标和明细同步变化；导出字段和页面一致；数据统计员只能看聚合统计和导出，不看单个农户手机号；导出要记日志。
- **验收标准**：筛选后指标和明细一致；导出文件能打开且字段与页面一致；统计员看不到完整手机号；导出有日志；没有数据时导出空表不报错。
- **分级/阶段**：中 / 第二阶段。

### 3.4 趋势图与 PDF

- **谁用**：直播管理员、数据统计员。
- **做什么**：按日、周、月看趋势；导出 PDF 报表。
- **输入/输出**：输入时间范围、统计维度；输出趋势图和 PDF。
- **规则与异常**：趋势数据和明细一致；PDF 中文不能乱码；没有数据时显示空图或“暂无”。
- **验收标准**：趋势图和明细一致；PDF 能打开、中文正常、页数与内容完整；没有数据不报错。
- **分级/阶段**：低 / 第二阶段。

### 3.5 农户个人数据

- **谁用**：农户。
- **做什么**：查看本人已完成的直播场次、卖出的农产品数量。
- **输入/输出**：输入时间范围；输出本人直播场次、销售数量、明细。
- **规则与异常**：只能看本人；不能看别人；不能看完整手机号；不能导出全量数据。
- **验收标准**：只显示本人数据；换账号看不到别人；数量和统计页一致；没有数据时显示 0 或“暂无”。
- **分级/阶段**：中 / 第二阶段。

## 4. 二次验证与日志

### 4.1 二次验证

- **谁用**：系统管理员、直播管理员、数据统计员在敏感操作时使用。
- **做什么**：敏感操作前输入短信验证码，验证通过才继续。
- **输入/输出**：输入 6 位短信验证码；输出验证结果和操作结果。
- **规则与异常**：验证码 5 分钟内有效，最多试 5 次；一次一用；超时或错误要重新获取；敏感操作包括查看完整手机号、导出敏感数据、修改角色、停用账号、导出日志；验证失败要记日志。
- **验收标准**：不输验证码不能做敏感操作；错误验证码被拒绝；超过 5 次锁定；验证码过期失效；验证成功后操作完成；失败有日志。
- **分级/阶段**：中 / 第二阶段。

### 4.2 日志查询与导出

- **谁用**：系统管理员。
- **做什么**：按操作人、时间、操作类型查询日志，并导出。
- **输入/输出**：输入查询条件；输出日志列表和表格文件。
- **规则与异常**：日志只能查和导出，不能修改、不能删除；默认保留 180 天；导出要二次验证并记日志；普通角色看不到日志。
- **验收标准**：能按人、时间、类型查到；导出字段完整；没有修改和删除入口；导出有二次验证和日志；超过保留期的日志按规则清理。
- **分级/阶段**：中 / 第二阶段。

### 4.3 日志防篡改

- **谁用**：系统管理员查看，系统自动校验。
- **做什么**：每条日志带校验值，前后关联；每天自动校验一次，发现改动就告警。
- **输入/输出**：输入日志写入；输出校验结果和告警。
- **规则与异常**：日志只能追加；校验不通过时标红并通知系统管理员；不能通过业务界面改日志。
- **验收标准**：正常日志校验通过；直接改数据库里的日志能被发现；发现后系统管理员收到告警；业务界面没有改日志入口。
- **分级/阶段**：低 / 第二阶段。

## 5. AI 助手

### 5.1 知识库文档增删改查

- **谁用**：直播管理员增删改查；系统管理员查看。
- **做什么**：上传、查询、修改、删除、启用、停用知识库文档。
- **输入/输出**：输入文字版 PDF、DOCX、MD、TXT，单文件不超过 20MB；输出文档状态和知识库内容。
- **规则与异常**：支持新增、删除、修改、查询；解析失败要说明原因；本期只保证文字版 PDF，扫描件或图片 PDF 先提示暂不能解析，后续升级 OCR；删除要二次确认；停用后不再被检索；系统管理员只能查看，不能改内容；每次变更记日志。
- **验收标准**：能新增、查询、修改、删除文档；文字版 PDF 能解析；损坏文件显示失败原因；扫描件或图片 PDF 提示暂不能解析并记录，不能算解析成功；删除有二次确认；停用后问答查不到；启用后能查到；系统管理员没有修改入口；变更都有日志。
- **分级/阶段**：中 / 第二阶段。

### 5.2 问答、引用、拒答、转人工

- **谁用**：四种角色都可以提问。
- **做什么**：用自然语言问预约规则、排队规则、农产品溯源等问题。
- **输入/输出**：输入问题；输出回答、来源引用、拒答提示或转人工入口。
- **能力边界**：AI 助手是只读的——只能查知识库并回答，不能提交、修改、取消预约，不能改排队、候补和农户资料，也不能查看农户业务数据。
- **规则与异常**：只回答知识库里的内容；回答要带文档名和段落来源；没有依据时明确说“知识库暂无相关内容”，不能编造；答不上来可以转人工；转人工要生成记录。
- **验收标准**：规则问题回答带来源；没有依据的问题明确拒答；说“帮我取消预约”不产生任何业务操作；问别人预约或手机号不能回答；转人工有记录。
- **分级/阶段**：中 / 第二阶段。

### 5.3 评测、版本与降级

- **谁用**：直播管理员维护，系统管理员查看。
- **做什么**：用 50 个问题做评测；知识库版本可以回滚；外部大模型不可用时降级。
- **输入/输出**：输入评测问题集；输出评测报告、版本记录和降级结果。
- **规则与异常**：前 5 条检索命中率不低于 85%；答案正确率不低于 80%；引用准确率不低于 90%；该拒答时拒答率不低于 85%；版本回滚后能查到旧内容；降级顺序为主模型、备用模型、常见问题关键词、人工。
- **验收标准**：评测报告有四项指标；指标不达标不能上线；回滚后旧版内容能查到；模拟主模型不可用时能降级；降级后仍能回答常见问题或转人工。
- **分级/阶段**：低 / 第二阶段。

## 8. 权限与页面

### 8.1 增强功能权限

> 角色权限沿用需求-06 的 1.3.1；系统管理员仍有最高权限，但日常不操作业务数据。

| 功能 | 系统管理员 | 直播管理员 | 农户 | 数据统计员 |
|---|---|---|---|---|
| 预约调整审批 | 查看 | 审批 | 申请/撤销/查看本人 | 无 |
| 直播销售录入 | 查看 | 新增/修改/查询 | 无 | 查看/导出 |
| 统计报表 | 查看/导出全量 | 查看/导出 | 查看本人 | 查看/导出 |
| 二次验证 | 使用 | 使用 | 无 | 导出时使用 |
| 日志查询 | 查看/导出 | 无 | 无 | 无 |
| 日志防篡改 | 查看/处理告警 | 无 | 无 | 无 |
| AI 知识库 | 查看 | 新增/删除/修改/查询 | 无 | 无 |
| AI 问答 | 可提问 | 可提问 | 可提问 | 可提问 |
| 通知模板 | 新增/删除/修改/查询 | 查看/使用 | 无 | 无 |
| 校准提醒 | 查看 | 新增/修改/查询 | 无 | 无 |

### 8.2 页面

- **直播管理员**：预约调整审批、销售录入、统计报表、AI 知识库、通知模板查看、校准提醒。
- **系统管理员**：账号与角色、二次验证、日志查询与告警、通知模板、统计全量。
- **农户**：我的预约里看调整申请、个人数据、AI 问答。
- **数据统计员**：统计报表、导出、AI 问答。

**验收标准**：每个角色只能看到自己的菜单；没有权限的页面直接访问被拒绝；统计员看不到单个农户明细。

## 9. 实施顺序

| 顺序 | 先做什么 | 为什么 |
|---|---|---|
| 1 | 预约调整 | 依赖核心预约，做完才能处理改期 |
| 2 | 直播销售录入 | 统计指标的数据来源 |
| 3 | 四项指标、筛选、导出 | 依赖销售录入和完成标记 |
| 4 | 趋势图、PDF、农户个人数据 | 依赖指标口径稳定 |
| 5 | 二次验证、日志查询、防篡改 | 依赖登录和基础日志 |
| 6 | AI 知识库、问答、评测 | 依赖知识库文档和解析 |
| 7 | 通知模板、校准提醒 | 低优先级，最后做 |

## 10. 默认口径

以下先按默认做，评审时你可以直接改：

| # | 事项 | 默认口径 |
|---|---|---|
| 1 | 二次验证方式 | 短信 6 位验证码，5 分钟有效，最多 5 次 |
| 2 | 日志保留 | 默认 180 天 |
