| 项 | 内容 |

| 用途 | 锁定 MVP、指导迭代排期、范围变更时快速判断"砍不砍" |

---

## 1. 三层范围定义

| 层级 | 定义 | 内容 | 交付要求 |
|---|---|---|---|
| **MVP（P0）** | 缺任一功能则系统不成立、无法演示 | 农户/资源建档、预约提交与冲突校验、审核、调整/取消、排队、候补、核心通知、四角色权限、审计日志、4 项核心统计、RAG 基本问答 | 必须 100% 通过 P0 用例 |
| **V1.0（P1）** | 完整体验与可运营所需 | 我的预约/排队、通知中心、趋势图、PDF、个人数据、日志查询、二次验证、SLA 提醒、冷却/清理、RAG 评测与版本 | 通过率 ≥95%，允许带已知问题上线 |
| **V1.1（P2）** | 加分项/可选，资源富余再做 | 校准提醒、第三方平台同步、短信模板报备 | 开关默认关闭，不影响主线 |

> **判定口诀**：删掉它，系统还能不能完成"农户预约 → 审核 → 排队 → 候补 → 通知 → 统计"闭环？能 → P1/P2；不能 → P0。

## 2. 迭代与范围映射

| 迭代 | 周次 | 主题 | 交付需求 | 退出标准 |
|---|---|---|---|---|
| S0 | W1–W2 | 需求与方案基线 | 全部 SRS + 架构 + 原型 + 环境 | G1 评审通过，需求基线冻结 |
| S1 | W3–W5 | 地基：基础信息 + 权限骨架 | BASE-01~06/08~11/13；AUTH-01/02/05 | 可登录、可建档、可查资源；单测覆盖 ≥60% |
| S2 | W6–W8 | 预约 + 通知 | BOOK-01~09/13/14；NOTI-01~05；AUTH-03 | 预约—审核闭环可演示；冲突用例全绿 |
| S3 | W9–W11 | 调整 + 排队 + 候补 | BOOK-10~12；QUEUE-01~12；NOTI-06 | 预约—审核—排队—候补全流程可演示 |
| S4 | W12–W13 | 统计 + 审计加固 | STAT-01~07；AUTH-04/06/07/08；BOOK-09；QUEUE-13；BASE-07 | 报表可导出；越权/审计用例全绿 |
| S5 | W14 | RAG 联调 + 系统加固 | RAG-01~07；BASE-12；NOTI-07；NFR 全部 | 评测达标；性能/安全测试通过（RAG 编码自 W12 并行启动） |
| 交付 | W15 | 部署、UAT、答辩 | O5 全套 | G5 验收签字 |
| 缓冲 | W16 | 遗留缺陷、答辩材料、春节前收尾 | 不安排新功能 | 无阻断问题 |

### 2.1 与原始四阶段的对应

| 原始阶段 | 本项目安排 | 说明 |
|---|---|---|
| 第一阶段 需求分析与方案设计 | S0（W1–W2） | 需求清单、架构、库表、原型、客户代表评审 |
| 第二阶段 核心功能开发 | S1–S4（W3–W13） | 按"基础→预约→通知→排队→统计→权限"推进；**权限骨架因技术依赖前置到 S1**，完整审计放 S4 |
| 第三阶段 系统测试与优化 | W12–W15（与 S4/S5 重叠） | 测试左移：S1 起每迭代回归，不等到最后 |
| 第四阶段 部署与交付 | W15（W16 缓冲） | 部署、备份演练、交付物、答辩 |

> **偏差说明**：原文要求权限模块最后开发。但鉴权是所有接口的地基，故 S1 先做"登录 + RBAC 骨架 + 日志切面"，S4 再做"数据级权限 + 二次验证 + 日志查询与哈希链"。此调整已在 G1 评审报备。

## 5. 如果工期被压缩：砍功能的顺序

> 原则：**先砍"锦上添花"，再砍"体验增强"，绝不砍"闭环与合规"**。

| 顺位 | 砍什么 | 影响 | 替代方案 |
|---|---|---|---|
| 1 | BASE-12 第三方同步 | 无 | 手工导入 |
| 2 | BASE-07 校准提醒 | 设备管理弱化 | 管理员线下台账 |
| 3 | NOTI-07 短信模板报备 | 仅生产合规 | 演示用模拟网关 |
| 4 | STAT-05 PDF 导出 | 报表少一种格式 | 仅 Excel |
| 5 | STAT-03 趋势图 | 可视化弱化 | 表格 + 数字 |
| 6 | RAG-03/07 版本与评测 | 知识库运营弱化 | 人工抽检 |
| 7 | AUTH-08 日志哈希链 | 防篡改弱化 | 只读权限 + 备份 |
| 8 | QUEUE-13 自动清理 | 需人工关队列 | 管理员手动 |
| ⛔ 不可砍 | 冲突校验、排队/候补、权限、脱敏、审计、备份 | 系统不成立/违规 | — |
