# 助农直播管理系统 · 用户故事与验收场景（BDD）

| 项 | 内容 |
|---|---|
| 文档编号 | R1-03 |
| 版本 | v1.0 |
| 编制 | P1（产品）/ P6（UI 走查配合） |
| 用途 | 需求评审、开发自测、测试用例设计、UAT 验收的共同语言 |
| 约定 | 场景编号 `SCN-<域>-<NN>`；每条场景必须能反标到 `REQ` |

> **读法**：Given = 前置数据与状态；When = 用户/系统动作；Then = **可观测**结果（页面文案、状态码、数据库状态、通知）。写不出 Then 的场景不算验收场景。

## 2. 验收场景

### 2.1 基础信息与资源

#### SCN-BASE-01 手机号在列表与详情中脱敏
- **REQ**：BASE-02、AUTH-07
- **Pre-req**：农户 `NF2025001` 手机号 `13812345678`；管理员已登录。
```gherkin
Given 管理员打开农户列表
When  页面加载完成
Then  联系方式列显示 "138****5678"，响应体中不含 "13812345678"
When  系统管理员点击"查看完整号码"并完成二次验证、填写原因
Then  显示 "13812345678"，且操作日志新增一条"查看完整手机号"
When  直播管理员尝试查看完整号码
Then  无查看入口，直接调用接口返回 403
When  农户 NF2025002 尝试访问 NF2025001 的详情
Then  返回 403，响应体不含手机号任何片段
```

#### SCN-BASE-02 未认证农户不能预约
- **REQ**：BASE-13、BOOK-01
- **Pre-req**：农户 `NF2025003` 资质状态为"待审核"。
```gherkin
Given 农户 NF2025003 已登录
When  其提交直播预约
Then  返回 403 FARMER_NOT_CERTIFIED
And   页面提示"请先完成资质认证"并给出上传入口
And   数据库无新增 booking 记录
```

#### SCN-BASE-03 设备编号按规则生成
- **REQ**：BASE-05
- **Pre-req**：场地 `C001` 下已有 1 台设备。
```gherkin
Given 管理员在场地 C001 下新增设备
When  保存成功
Then  设备编号为 ZB-C001-02
And   管理员手工传入编号 "ZB-X-99" 时返回 400
```

#### SCN-BASE-04 维修中设备不出现在可约列表
- **REQ**：BASE-06、BASE-10
```gherkin
Given 设备 ZB-C001-02 状态为"维修"
When  农户查询 2026-10-20 10:00-12:00 的可用资源
Then  结果中不包含 ZB-C001-02
And   直接指定该设备预约返回 409 DEVICE_UNAVAILABLE
```

### 2.2 预约提交与审核

#### SCN-BOOK-01 农户成功提交预约（主流程）
- **REQ**：BOOK-01、BOOK-02、BOOK-03、BOOK-04
- **Pre-req**：农户已认证；2026-10-20 10:00–12:00 设备 `ZB-C001-01`、场地 `C001` 空闲。
```gherkin
Given 农户 NF2025001 已登录且资质已认证
And   当前时间为 2026-10-19 09:00
When  其提交：县域=寿县、主题="寿县草莓专场"、时段=2026-10-20 10:00-12:00、产品=[草莓/5斤装]
Then  返回 201 与 bookingId（形如 Y202610190001）
And   状态为 PENDING_REVIEW
And   2 条设备槽位 + 2 条场地槽位处于预占/待审核态（按实现约定）
And   管理员待审核列表 5 秒内出现该记录
```

> 说明：提交时是否预占资源由 D2-01 决策——**默认"提交即预占（软锁），驳回/取消释放"**，避免审核期间被抢。若采用"审核时锁"，需在 BOOK-03 AC3 中体现二次校验。

#### SCN-BOOK-02 非整点时段被拒绝
- **REQ**：BOOK-02
```gherkin
Given 农户已认证
When  提交时段 "2026-10-20 10:30-12:30"
Then  返回 400 SLOT_NOT_ALIGNED
And   提示"直播时段需按整点选择"
```

#### SCN-BOOK-03 资源冲突时提示排队
- **REQ**：BOOK-03、QUEUE-01
- **Pre-req**：同日同时段已被农户 B 预约成功。
```gherkin
Given 目标时段设备与场地均被占用
When  农户 A 提交预约
Then  返回 409 RESOURCE_CONFLICT
And   响应含 queueAvailable=true 与冲突资源编号
And   页面展示"该时段已满，是否进入排队？"
When  农户 A 点击"进入排队"
Then  生成排队号 Q-NF2025001-20261020-001，状态 WAITING，顺位 1
```

#### SCN-BOOK-04 管理员驳回必须给理由与推荐时间
- **REQ**：BOOK-08
```gherkin
Given 一条待审核预约
When  管理员仅填写 4 字原因并提交驳回
Then  返回 400，提示原因至少 5 字
When  管理员填写原因"资质照片模糊，请重传"，推荐时间 2026-10-21 10:00
Then  状态变为 REJECTED
And   农户收到站内通知，含原因与推荐时间
And   通知内"重新预约"按钮跳转并预填推荐时间
```

#### SCN-BOOK-05 审核通过的并发幂等
- **REQ**：BOOK-07、BOOK-13
```gherkin
Given 预约处于 PENDING_REVIEW
When  两个管理员会话同时点击"通过"
Then  仅 1 次返回 200，另 1 次返回 409 INVALID_STATE
And   resource_lock 中该预约的槽位只有一组，无重复
And   booking_status_history 只有 1 条 PENDING_REVIEW→APPROVED
```

#### SCN-BOOK-06 开播前 12 小时边界可调整
- **REQ**：BOOK-10、BOOK-11
- **Pre-req**：当前 2026-10-19 10:00，预约开始 2026-10-20 10:00（恰好 24h）。
```gherkin
Given 预约开始时间为 24 小时后
When  农户提交调整到 2026-10-20 14:00
Then  返回 200，调整单状态 PENDING
And   原 10:00 资源仍保持锁定
When  管理员审批通过
Then  原 10:00 槽位释放、14:00 槽位占用
And   农户收到调整成功通知
```
```gherkin
Given 预约开始时间距当前仅 11 小时 59 分
When  农户提交调整
Then  返回 403 ADJUST_WINDOW_CLOSED
And   页面提示"开播前 12 小时内不可调整，仅可取消"
```

#### SCN-BOOK-07 取消预约触发候补
- **REQ**：BOOK-12、QUEUE-07
```gherkin
Given 预约 Y202610190001 已通过，队列中有 2 人排队
When  农户取消预约并选择原因"农产品临时缺货"
Then  状态变为 CANCELLED，资源 5 秒内释放
And   队首农户收到候补确认通知，状态 CANDIDATE
And   取消原因出现在审计日志与统计明细中
```

### 2.3 排队与候补

#### SCN-QUEUE-01 顺位按申请时间严格排序
- **REQ**：QUEUE-02、QUEUE-03、QUEUE-04
```gherkin
Given 农户 A、B、C 在 09:00、09:01、09:02 依次加入同一队列
When  农户 C 查看"我的排队"
Then  显示"您当前排在第 3 位，预计等待 2 场直播"
And   排队号序号依次为 001、002、003
```

#### SCN-QUEUE-02 前序取消后顺位前移并通知
- **REQ**：QUEUE-03、QUEUE-06
```gherkin
Given A(1)、B(2)、C(3) 在同一队列
When  A 退出排队
Then  5 秒内 B 变为第 1 位、C 变为第 2 位
And   B、C 各收到 1 条"顺位更新"站内通知
And   同一变化不重复通知（刷新页面不新增）
```

#### SCN-QUEUE-03 重复排队被拒绝
- **REQ**：QUEUE-10
```gherkin
Given 农户 A 已在该设备该时段排队（Q-...-001）
When  再次点击"进入排队"
Then  返回 409 ALREADY_QUEUED
And   提示"您已在队列中，当前第 1 位"，不产生第二条排队
```

#### SCN-QUEUE-04 候补确认生成预约
- **REQ**：QUEUE-08
```gherkin
Given 农户 A 收到候补通知，截止时间 2026-10-20 09:00
When  A 在 08:59 点击"确认预约"
Then  生成状态为 APPROVED 的预约并锁定资源
And   排队状态变为 CONFIRMED
And   A 与管理员各收到确认通知
And   操作记录含选择结果、时间、IP
```

#### SCN-QUEUE-05 候补超时自动顺延
- **REQ**：QUEUE-09
```gherkin
Given 农户 A 的候补截止时间为 09:00，队列下一位为 B
When  时间到达 09:00 且 A 未响应
Then  A 状态变为 EXPIRED 并收到"已过期"通知
And   B 立即变为 CANDIDATE 并收到候补通知
And   资源保持可用，未产生空转
```

#### SCN-QUEUE-06 确认后取消触发 72 小时冷却
- **REQ**：QUEUE-11
```gherkin
Given 农户 A 候补确认成功，预约 2026-10-20 10:00
When  A 在 2026-10-19 15:00 取消该预约
Then  写入冷却记录，解禁时间 2026-10-22 15:00
When  A 在 2026-10-20 10:00 再次对该设备排队
Then  返回 403 COOLING_DOWN，提示"2026-10-22 15:00 后可再次排队"
And   A 对其他设备排队不受影响
```

#### SCN-QUEUE-07 候补窗口不足 30 分钟直接顺延
- **REQ**：QUEUE-09
```gherkin
Given 距离直播开始仅剩 25 分钟，队列有 A、B
When  资源被释放
Then  不为 A 生成候补 offer，记录 SKIP_TOO_LATE
And   B 同样被跳过，队列置 CLOSED
And   管理员收到"资源临期释放未成交"提醒
```

#### SCN-QUEUE-08 50 并发加入不重号
- **REQ**：QUEUE-12
```gherkin
Given 同一设备同一时段队列为空
When  50 个农户并发加入
Then  50 条排队记录全部成功，排队号 001-050 连续无重复
And   顺位 1-50 无重复
And   对账结果：总数 = 各状态数量之和
```

### 2.4 通知

#### SCN-NOTI-01 短信失败后重试并站内兜底
- **REQ**：NOTI-03、NOTI-04
```gherkin
Given 短信网关返回失败
When  系统发送"设备故障预警"
Then  记录 FAILED 与失败原因
And   1/5/15 分钟后各重试 1 次，最多 3 次
When  3 次仍失败
Then  状态置 DEAD，生成站内兜底通知，管理员收到告警
And   农户在通知中心仍能看到该预警
```

#### SCN-NOTI-02 开播前 1 小时提醒只发一次
- **REQ**：NOTI-06
```gherkin
Given 预约 2026-10-20 10:00 已通过
When  定时任务在 09:00、09:05、09:10 各扫描一次
Then  仅在 09:00±5 分钟内产生 1 条提醒
And   农户只收到 1 条站内 + 1 条短信（若开启）
```

#### SCN-NOTI-03 改期后不发旧提醒
- **REQ**：NOTI-06、BOOK-11
```gherkin
Given 预约原定 10:00，已生成开播提醒任务
When  管理员通过调整到 14:00
Then  原 09:00 提醒任务被取消
And   新提醒按 13:00 重新生成
```

## 4. UAT 验收脚本（邀请同学测试用）

| 步骤 | 任务 | 观察点 | 通过标准 |
|---|---|---|---|
| 1 | 注册/登录 → 提交一次预约 | 步骤数、字段理解成本 | ≤3 步、≤2 分钟 |
| 2 | 故意选已被占时段 | 是否看懂"排队"提示 | 能自主选择排队 |
| 3 | 查看排队顺位 | 是否理解"预计等待" | 能复述当前位次 |
| 4 | 收到候补通知并确认 | 是否知道截止时间 | 在时限内完成 |
