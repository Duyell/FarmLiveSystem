# 助农直播管理系统 · 需求追踪矩阵（RTM）

| 项 | 内容 |
|---|---|
| 文档编号 | R1-04 |
| 版本 | v1.0 |
| 编制/维护 | P1（维护）/ P5（测试侧核对） |
| 更新时机 | 需求变更、接口变更、用例新增、迭代验收后 |
| 当前基线 | SRS v1.0（81 条）+ 用例集 v1.0（78 条） |

> **用法**：任一需求可查到"哪份设计、哪个接口、哪张表、哪条用例、哪个迭代"；反向由用例编号 `[REQ-XXX-NN]` 回到需求。
> **红线**：P0 需求必须至少 1 条用例；出现"裸奔需求"（无用例）即 G3 门禁不通过。

## 10. 追踪健康度检查（每次迭代末执行）

| 检查项 | 方法 | 通过标准 |
|---|---|---|
| 裸奔需求 | 集合差：REQ − 有用例的 REQ | P0 为 0；P1 ≤0 |
| 孤儿用例 | 集合差：TC − 能反标 REQ 的 TC | 0 |
| 断链设计 | 每条 P0 REQ 是否有设计章节与 API | 100% |
| 断链数据 | 每条 P0 REQ 是否落到具体表 | 100% |
| 用例编号 | 用例名是否以 `[REQ-XXX-NN]` 开头 | 100% |
| 变更同步 | 最近 7 天变更的需求是否更新 RTM | 100% |

> 本项目当前检查结果：裸奔 0、孤儿 0、断链 0（v1.0 基线自查）。
